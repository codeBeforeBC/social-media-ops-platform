# YOYO 运营平台：资产库与视频需求补充 v0.3

2026-10-04。承接《产品修订说明-v0.2》，继续采用 AI 自动采集选题、内容制作单、团队内部审核及带开奖提醒的排期日历。此轮为文档和静态效果图，不实现网站，不创建真实通知，不生成实际视频。

## 1. 资产库范围

用户已确认拥有规范 PDF 及多种 2D、3D 素材，同时需要管理视频素材与视频发布内容。当前仅收到规范 PDF 与账号截图，没有收到其他原始资产；效果图里的素材卡片与视频时长均为示例，不能当作实际入库清单。

资产库设置两个主入口：

- **素材库**：可复用的规范、角色形象、动作、视频片段、声音等。
- **成品归档**：完成的图文发布包、视频成片、封面、发布文案、最终版本和实际发布记录。

同一个素材可被多篇内容使用；同一篇内容可关联多个素材。素材所属媒介不等于成品形式：2D 图可以做视频，3D 工程可以输出静帧或动画，视频经允许可截帧用于图文。

## 2. 分类与文件管理

| 分类 | 内容 | 首版产品处理 |
|---|---|---|
| 规范文档 | PDF、规则说明 | 文档阅读、版本、生效状态、规则出处 |
| 2D 素材 | 透明图、矢量、分层源文件、表情、动作 | 支持可读图片预览，保留可编辑原文件；专有格式采用关联缩略图 |
| 3D 源文件 | 模型、材质、贴图、绑定、动画工程等 | 原文件或完整包保存，记录制作软件/版本、依赖和预览文件；不承诺在线编辑或渲染所有格式 |
| 渲染图 | 3D 静帧、透明背景渲染 | 图片预览，并关联源工程与版本 |
| 视频与动效 | 原始片段、角色动作、合成片段、完整视频 | 可支持格式使用播放器；记录时长、画幅、分辨率、帧率、音轨等实际可读信息 |
| 音频 | 配音、音效、音乐 | 播放、时长、版本、使用范围和来源 |

实际格式支持清单由开发拿到样本后确定。文件扩展名不能替代真实格式检查。暂不支持在线预览时显示“暂不支持预览”，提供缩略图关联与下载；不能呈现空白并假装文件可用。3D 包的贴图和相对路径尽量保持完整，缺依赖时显示缺项。

上传支持批量、拖拽、进度、失败重试；大文件支持断点续传作为可评估需求。重复文件提示复用或作为新版本，不能默默覆盖旧版本。上传成功、预览处理中、预览失败、待内部确认、可复用、已停用分别显示。

## 3. 页面功能

资产卡显示：缩略图、名称、类型、版本、使用状态；视频卡增加播放标识和实际时长。支持文件夹、搜索、类型筛选、表情/动作/场景标签、收藏和最近使用。

右侧详情展示：原文件、预览文件、源工程关系、关联成品、标签、来源、使用范围、更新时间、内部备注。主要动作是“加入内容制作单”“下载原文件”“查看使用记录”。

素材进入一个制作单只表示被选用，不代表审核通过。未确认、过期或停用素材可以作为草稿中的待处理引用，但内部确认前必须处理提示。发布内容绑定实际使用的素材版本，后续新版本上传不改写旧作品记录。

AI 可建议标签、描述、选题适配与可复用素材组合；自动标签是建议，允许批量人工修正。搜索“开心出发”可以返回相应图、动作片段和声音，但不能凭模型想象生成不存在的文件路径。

## 4. 内容工作间支持图文与视频

共同部分：选题与证据、目标人群、关注理由、内容制作单、关联素材、标题正文、内部审核、排期、实际发布和数据。

| 图文模式 | 视频模式 |
|---|---|
| 每页画面与页内文案 | 每个镜头的时长、画面动作、字幕与声音 |
| 分页预览和图片顺序 | 视频播放器、镜头清单、字幕预览和封面选择 |
| 图片与文案交付 | 成片、封面、字幕/配音稿、发布文案交付 |
| 图片清晰度、裁切、文字与顺序检查 | 画面、声音、字幕、封面、素材使用范围与成片版本检查 |

视频制作单增加：目标时长、画幅、镜头序号、起止时间、画面描述、关联素材、字幕、配音建议、音效/音乐说明、封面方案。没有成片时明确“分镜提案”；上传文件并可预览后才显示实际成片信息。

第一版 AI 提供策划、分镜、文案与素材推荐；团队使用现有设计/剪辑工具制作后上传。页面中的镜头清单不是完整剪辑软件，不因为画了播放器就承诺网页内剪辑、配音生成或自动动画生产。

“图文/视频”是不同内容类型的入口。创建时选择类型；已有制作单改变类型需确认并转换或另建版本，保留原稿，不把图片排序直接解释为视频分镜。

## 5. 视频内部确认与归档

视频流程：选题确认 → 视频制作 → 内部审核 → 待发布 → 已发布 → 待复盘。成片、字幕、声音、封面、标题或正文的更改都会使原内部确认失效。

保留可编辑工程（若提供）、依赖素材、实际成片、封面、发布文案与内部确认记录。音频或角色动作素材的使用范围不能从文件存在推定。用内部检查清单完成核对，不另设外部品牌审核节点。

发布包整理已有文件及文案，不等于平台已经重新编码或发布视频。上传失败不能生成可播放状态；没有实际发布链接或确认时不记为已发布。

## 6. 排期与复盘兼容视频

日历可筛选图文/视频，并显示制作、内部确认、计划发布、数据回收和开奖提醒。视频可以有更长制作周期与依赖项；AI 依据用户真实产能安排，不把图文和视频默认成同样工作量。

开奖属于活动属性，与发布形式分开：图文活动帖和视频活动帖都可以设置参与截止、开奖时间、负责人及提前提醒。沿用 v0.2 的“待开奖、已开奖、已公布”和逾期处理。

视频数据保存后台实际可得的播放量、观看时长、完播相关指标、互动与新增关注归因，并记录各字段定义和窗口；若后台没有则留空。不能从视频长度推算平均观看时长，也不能把播放次数当成独立观看人数。图文与视频分组比较，需要混合报告时保留口径差异。

## 7. 补充验收

1. PDF、2D、3D 源文件、渲染图、视频与音频能分类存储；专有格式无预览时给出明确替代操作。
2. 3D 源工程与渲染输出、视频片段与最终成片可建立关联；源文件不被预览文件替换。
3. 一个素材可关联多个内容制作单，能查看真实使用记录和版本。
4. 上传预览或生成缩略图失败不会把未完成文件标作可用；重试不重复创建素材。
5. AI 推荐只引用实际存在且有记录的素材；自动标签可人工纠正。
6. 视频制作单可明确镜头时间、字幕、声音和封面；镜头时长与目标时长冲突时提示。
7. 成片内部确认与具体文件版本绑定，替换成片后重新确认。
8. 图文和视频活动均可设置开奖提醒；不因内容类型不同漏掉活动提醒。
9. 视频复盘只使用实际采集到的指标，缺失不猜填，播放与阅读不混用。

## 8. 设计交付说明

本轮使用内置 imagegen 生成 IP 资产库和视频模式工作间静态效果图，提示词随文件提供。规范文档卡片封面、素材缩略图、源文件图标和播放器画面为 UI 示意；正式界面应读取实际文件封面与预览，不把生成图片当成真实素材文件。
