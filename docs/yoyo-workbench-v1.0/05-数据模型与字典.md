# 05 数据模型与字典

v1.0｜2026-10-06。逻辑模型，可映射到具体关系数据库；不是建表脚本。枚举以 03 为准。

## 当前文件格式约束（CHANGE-002）

素材上传purpose=asset，仅接受PNG；品牌规范purpose=guideline，仅接受PDF。素材category当前允许2d/render，对应PNG素材/PNG渲染图；PDF不创建普通Asset，而由规范版本绑定原件及PDF页序。FileObject仍承载不可变原件和独立预览。文件扩展名、MIME及内容一致性须校验，其他素材格式拒绝上传。

下文工程/音视频字段和枚举为后续扩展模型保留，不表示本版接受对应文件；视频片段范围与工程原件关联待下版。[决策依据](../decisions/ADR-004-S2首版PNG素材范围.md)。

## 1. 通用约定

实体 ID 使用不可变、不暴露顺序含义的字符串 UUID。各工作区对象包含 id、workspace_id、created_at、updated_at、created_by、version；version 为并发控制整数，不等于文件业务版本。时间存 UTC 时间戳，显示用 IANA 时区，默认 Asia/Shanghai；日期范围采用 start 含、end 不含，并保存源页面显示的原始范围。软归档用 archived_at。

数值使用精确 decimal，缺失用 null＋missing_reason，不以 0 代替。枚举值使用英文、UI 使用中文。字符串建议通用上限：名称 200 字符、描述 10,000 字符、URL 4,096 字符；内容正文上限与平台发布上限分离，配置而非在图中照抄计数器。

## 2. 身份、账号与品牌

| 实体 | 核心字段（除通用字段） | 约束/关系 |
|---|---|---|
| Workspace | name, timezone, settings | 默认一个工作区；保存提醒与配额设置 |
| User / Membership | auth_subject, display_name；user_id, roles[], active | 唯一(workspace_id,user_id)，不保存平台密码 |
| SocialAccount | platform, platform_user_id, display_handle, name, profile_url, owner_id, timezone | 唯一(workspace_id,platform,platform_user_id)；小红书内部用户 ID 与展示小红书号分字段 |
| BrandRuleSet | name, edition, status, source_file_id, activated_by/at | draft/active/retired；活动版本切换留历史 |
| BrandRule | rule_set_id, category, rule_text, source_page, severity, uncertainty_note | 手册事实与运营提案 category 区分；页码按 PDF 页序 |

## 4. 内容、版本、审核和发布

| 实体 | 核心字段 | 约束/关系 |
|---|---|---|
| Content | account_id, topic_id?, media_type, owner_id, status, current_revision_id, approved_revision_id?, review_state, actual_hours | media_type graphic/video；状态与版本引用必须一致 |
| ContentRevision | content_id, revision_no, parent_revision_id?, title, body, tags[], brief, payload_hash, rule_set_id, strategy_version, frozen_at | 唯一(content_id,revision_no)；提交后不可变 |
| GraphicPage | revision_id, position, visual_instruction, page_copy, asset_version_id?, publish_file_id? | 唯一(revision_id,position)，排序连续 |
| VideoShot | revision_id, position, start_ms, end_ms, action, subtitle, voiceover, sound, asset_refs | end>start；首版连续时间轴，空白/重叠需人工说明 |
| MediaDeliverable | revision_id, role, file_id, order?, metadata | role publish_image/final_video/cover/subtitle/editable_source；视频成片不能指向未完成文件 |
| AssetUsage | asset_version_id, revision_id, usage_role, clip_start/end_ms?, permission_snapshot | 记录版本，不只记录资产顶层 ID |
| Review | content_id, revision_id, payload_hash, status, requester_id, reviewer_id?, checklist, comment, decided_at | 一个版本最多一个有效 pending 请求；批准事务校验 current_revision |
| Publication | account_id, content_id, revision_id, platform_note_id, url, published_at, recorded_by, traffic_type, is_campaign, lifecycle | 唯一(account_id,platform_note_id)；traffic_type organic/paid/mixed/unknown |
| PublicationChange | publication_id, kind, actual_revision_id?, evidence, occurred_at | edited/deleted/reposted；重发另建 Publication |
| PublicationDraft | content_id, revision_id, partial_fields, verification_note | 缺 ID 的人工暂存；不得作为指标目标 |

brief 对象：goal、audience、follow_reason、emotion、deliverables、constraints、required_assets、estimated_hours、target_duration_ms?、aspect_ratio?。无配音/无活动可明确不适用。

发布修订补充字段：Content.supersedes_content_id（可空，同账号且禁止循环）；Publication.current_revision_id（初次等于 revision_id，后续变更经 PublicationChange 更新）。Publication.revision_id 保留初次版本，修订工作项依 03 流程处理。

## 5. 文件、资产和反馈

| 实体 | 核心字段 | 约束/关系 |
|---|---|---|
| FileObject | object_key, sha256, size_bytes, original_name, detected_mime, file_status, metadata, upload_session_id | 同工作区 hash 去重；跨区不泄露存在性 |
| UploadSession | requested_type, size, part_size, completed_parts, expires_at, status | 完成前不能被正式引用；过期分片清理 |
| Asset | name, category, ip_identity, folder_id?, tags[], owner_id, business_status, current_version_id | category guideline/2d/3d_source/render/video/audio |
| AssetVersion | asset_id, version_no, source_file_id, preview_file_id?, preview_status, parent_version_id?, usage_scope, valid_until?, software?, dependencies | 唯一(asset_id,version_no)；内容审批依赖使用范围 |
| AssetRelation | from_version_id, to_version_id, relation_type | source_of/render_of/derived_from；拒绝循环来源依赖 |
| Folder / Favorite | name,parent_id；user_id,asset_id | 父子同区且不可循环；收藏唯一 |

成品归档是 ContentRevision＋MediaDeliverable＋Publication 的视图，不复制第二套成品文件导致版本分叉。

## 8. 索引与保存策略

补充可追溯关系：MetricEvidence(observation_id, import_row_id, source_file_id?, active) 允许同一观察多个有效来源；ObservationSupersession(old_id, new_id, batch_id, reason) 记录更正链。两表支撑撤销某批而不破坏其他批来源。MetricObservation 的近似字段统一叫 is_approximate；10 中 approximate 是可读说明别名，接口统一使用 is_approximate。Notification 增加 channel，ReminderOccurrence 增加 skipped_reason，Campaign 增加 prize_summary、winner_count、participation_method；含个人资料的结果凭证按角色限制，不作为通用通知正文。

按工作区＋状态＋更新时间索引内容；按 owner＋due_at 索引日历待办；按 state＋due_at 索引提醒；按目标＋metric_key＋observed_at 索引指标；按连接＋external_id 索引来源。列表使用游标分页，排序加 ID 确保稳定。

默认先软归档。被作品、发布或证据引用的源文件拒绝普通硬删除；真正清理必须走引用扫描与管理员确认。运营指标、批准版本和提醒完成记录随项目保存；详细运行日志建议 90 天、临时失败分片 7 天，均为可配置提案；法规/公司要求更严格时由负责人调整。用户删除请求必须标识关联报告是否失效，不以备份为借口让已停用素材继续推荐。
