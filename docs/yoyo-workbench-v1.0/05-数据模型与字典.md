# 05 数据模型与字典

v1.2｜2026-10-09。目标逻辑模型，不是已经执行的迁移。状态以03为准，旧模型按[ADR-008](../decisions/ADR-008-删除排期日历与活动.md)兼容退出。

## 1. 通用约定

不可变UUID；对象带workspace_id、created_at/updated_at、created_by和并发version；账号对象带account_id。时间UTC存储＋IANA时区显示，默认Asia/Shanghai；窗口start含/end不含。精确decimal，缺失null＋missing_reason，不能用0代替。软归档保留关联和审计。

## 2. 身份、来源和选题

| 实体 | 关键字段/约束 |
|---|---|
| Workspace / User / Membership | 名称、时区、设置、身份、角色、active；(workspace,user)唯一 |
| SocialAccount | 平台、平台账号ID、展示号、名称、公开链接、owner、timezone；账号身份唯一且不能静默换ID |
| SourceConnection / CollectionRun | 提供方、credential_ref、能力、计划、health；连接/计划时段唯一；真实覆盖和错误保留 |
| SourceItem / SourceObservation | external_id/规范URL、原文摘要、发表/采集/过期时间；多次不可变观察和run_id，不把累计互动相加 |
| TopicCluster | 标题/主题、item_ids、method_version；不丢原始来源 |
| Topic | account_id、候选人群/需求/角度/关注理由/建议形式/栏目/估时/假设、status、generation_request_id、parent_topic_id? |
| TopicEvidence | topic_id、source_item_id?、observation_id?、claim、fact/inference/original_hypothesis；fact有冻结来源片段 |
| TopicDecision | topic_id、decision、reason、actor_id、owner_id?、decided_at；默认采纳唯一，不再有content_id |

候选不再包含required_asset_ids、rule_set_id、asset_version_ids或可发布载荷。历史候选JSON保持原记录，读取适配只呈现保留字段；不伪造新的模型输出证据。

## 3. 独立已发布笔记与反馈

| 实体 | 关键字段/约束 |
|---|---|
| Publication | account_id、platform_note_id、url、title、media_type(graphic/video)、published_at、recorded_by、traffic_type、lifecycle；(account_id,platform_note_id)唯一 |
| Feedback | publication_id?、source_url?、text、source_time?、category、author_alias?、consent_status、permitted_usage、reply_draft、status |

Publication不含content_id/revision_id/current_revision_id/approved_revision_id、正文、成品文件或制作工时必填项。既有Publication UUID保留，标题/形式从原记录映射，缺失字段人工补齐而不猜测。账号/笔记身份不允许普通更新；更正先审查已有关联并记录审计，外部删除保留历史，重发新ID另登记。移除is_campaign及活动关联；登记仅写身份/审计，不创建数据回收、排期或提醒Outbox。

不建设PublicationDraft、PublicationChange内容修订流程。需要更正登记元数据或标记外部删除时用版本更新与AuditLog；不管理外部正文修改历史。反馈许可unknown/internal_only/approved/revoked，无许可不进入公开回复草案的个人故事引用。

## 4. 日历与活动模型退出

CalendarEvent、Campaign、ReminderRule、ReminderOccurrence及排期建议不属于目标模型；活动规则、开奖/公告凭证、计划时间和回收节点不再存储。不存在的业务表不补建；已有实现中的活动标记/提醒池约束按S11兼容迁移收口，保留旧记录和历史审计。

## 5. 导入文件、指标和复盘

| 实体 | 关键字段/约束 |
|---|---|
| FileObject / UploadSession | 私有object_key、sha256、size、original_name、detected_mime、purpose、account_id/引用范围、file/preview状态；会话分片/期限及取消恢复 |
| ImportBatch / ImportRow | account_id、input_file_ids、parser_version、status、confirmed_by/at、supersedes_batch?；原始识别、图片区域、候选目标/指标/值、置信、纠正和状态 |
| MetricDefinition / MetricObservation | 定义key/unit/scope/aggregation/version；account/publication目标、value/null、窗口或观察时间、is_approximate、traffic_type、来源和validity |
| MetricEvidence / ObservationSupersession | 多来源有效性；old/new/batch/reason，更正链支持撤销不破坏后续结果 |
| Calculation | calculation_id、输入观察集合、计算版本、窗口、结果和缺失原因 |
| Report / StrategyMemory | 报告period/status、计算/观察引用、facts/hypotheses/actions/missing_data；策略proposed/active/retired、证据、适用范围、确认人/时间 |
| Experiment | 假设、变量、publication_ids或topic_ids、窗口、指标、混杂因素、结果；不依赖Content |

purpose目标范围：import_screenshot/import_table/source_evidence，禁止asset/guideline/publish_image/campaign_evidence。导入证据权限经批次/账号引用校验，跨工作区hash不泄露存在性。不提供活动凭证上传或引用。格式/限额见04及10，在实施阶段验证。

## 6. 运行、索引和退出

Notification/DeliveryAttempt仅用于来源、任务、导入和报告结果/失败，按业务事件/接收人/通道去重，个人已读独立；无活动发生项或到期计划。

Job/AIRun记录类型、幂等、输入版本、租约、结果/错误、模型/提示词/Schema版本、用量和预算；Outbox与业务事务一致；AuditLog追加式，不修改历史操作者。按工作区/账号/时间+ID分页，按state/due_at索引任务、按目标/指标/窗口索引观察。

Content、ContentRevision、GraphicPage、VideoShot、MediaDeliverable、Review、ExportPackage、Asset及其版本/引用/关系/收藏、Folder、BrandRuleSet/BrandRule及PublicationDraft/生产修订关系、CalendarEvent/Campaign/ReminderRule/ReminderOccurrence取消。保留现有迁移001–024，不以删SQL或删Prisma实体代替迁移。先兼容Publication和决策关系、移除活动标记与提醒池、收口任务/文件引用，再移除旧表和触发器；共享不可变函数仍被来源/选题引用时保留。旧数据受限备份，文件对象经完整引用扫描后才可清理；普通运行不要求物理清除历史文件。
