# 09 · IP 资产库与媒体处理

> 2026-10-07范围覆盖：[CHANGE-002 / ADR-004](../decisions/ADR-004-S2首版PNG素材范围.md)已由用户确认。当前首版素材仅PNG，品牌规范保留PDF；本文其他素材格式的原设计与验收项属于下版规划，不能作为当前S2阻塞或已实现能力。

v1.0｜2026-10-06。对应 R05、R06、R10、R11。资产库管理可复用的官方素材，成品归档记录实际发布版本；二者通过引用关联。

## 首版文件能力矩阵

2026-10-08同步用户已确认的[CHANGE-002 / ADR-004](../decisions/ADR-004-S2首版PNG素材范围.md)。素材文件与品牌规范分别按用途校验，PDF是品牌规范入口的保留格式，不能作为普通素材上传。识别同时检查扩展名、MIME与文件内容，改后缀不能绕过限制。

| 用途 / 分类 | 首版接受的原件 | 首版处理 | 失败处理 |
|---|---|---|---|
| PNG素材 | PNG，包括透明PNG | 安全解码、缩略图、尺寸与透明通道信息 | 展示失败；损坏文件隔离，不能确认可用 |
| PNG渲染图 | PNG | 同PNG素材，记录来源与衍生版本 | 展示失败；不承诺关联或打开未支持的工程原件 |
| 品牌规范（独立管理） | PDF，保留已有约410 MB、37页手册 | 分页预览、PDF页序、文本检索、规则原文追溯及人工激活 | 展示解析失败；原件保留，不能以未解析规范建立有效规则 |

普通素材入口仅接受PNG；品牌规范入口仅接受PDF。其他格式在首版拒绝上传，不以“暂不预览但可归档”的方式接受。原件与预览分开保存，原件下载受权限控制；解析服务故障可重试，不能用低清预览替代原件。

## 下个版本目标

| 目标类型 | 计划格式 / 内容 | 下版需补验证 |
|---|---|---|
| 其他图片 | JPEG、WebP、SVG等 | 格式识别、转换与安全预览 |
| 2D工程 | PSD、AI等 | 原件归档、同版本导出预览与源软件说明 |
| 3D工程 | BLEND、C4D、FBX、OBJ、GLB、ZIP等 | 原件、外部依赖、配套渲染及安全处理 |
| 视频/动效 | MP4、MOV、WebM、GIF等 | 原件、播放代理、声音与片段范围 |
| 音频 | WAV、MP3、M4A等 | 原件、播放器、元数据与使用范围 |

这些是下版目标，不构成当前上传/归档/转码/兼容承诺。下版开始前重新评估范围、样本和估时，不把旧视频任务标为已完成。

## 上传与处理

1. 创建上传会话，返回容量上限、分片大小、过期时间和会话 ID。首版单文件上限2 GiB（2147483648字节），分片8 MiB；已有约410 MB规范PDF必须实际测试。
2. 分片断点续传；重复分片幂等。完成后校验实际字节数、哈希和文件类型；失败不能创建可用资产。
3. 原件写入私有存储，生成 FileObject；异步生成PNG缩略图、PDF分页预览及相应元数据。界面分别显示原件上传和预览处理进度。
4. 同一工作空间哈希相同提示重复，可复用 FileObject；不同业务资产仍可各有记录。禁止通过去重接口泄露其他空间文件存在性。
5. 不支持的格式拒绝上传，提示素材仅PNG、品牌规范仅PDF；工程原件及压缩包归档/展开留到下版。

上传取消清理未完成分片；已成功文件按引用清理策略处理。网络重连后查询服务器分片清单，不能重复上传已经完成的分片。预览失败不等于原件丢失，也不等于资产不可用。

## 元数据与版本

必填：名称、类别、来源、所属系列、负责人、使用状态。可选：表情、动作、场景、配色、节庆、适用形式、标签、关联规范版本、使用范围、授权有效期、来源PNG版本、关联PNG渲染图。来源工程原件及其依赖字段留到下版。

首版自动提取PNG尺寸、透明通道及文件大小，PDF页数、页序与文本；提取失败显示未知。素材分类为PNG素材/PNG渲染图，PDF独立进入品牌规范管理。时长、帧率、音轨、编码及工程依赖为下版目标；AI标签仅为建议，确认后入正式字段。

每次更新新建 AssetVersion。内容绑定具体版本；旧帖仍引用旧版本。退休素材不得加入新制作单，已有历史引用可读并提示状态。使用范围未确认的素材可以进入草稿，提交内部审核前必须确认或移除。新规则激活不自动判定历史帖子违规。

## 图文制作交付与下版视频规划

图文制作单：封面方向、逐页目的和文案、所需素材、画幅、交付清单。建议模板默认竖版 3:4；这是工作台模板建议，发布限制以当时平台确认结果为准。

以下视频文件交付属于下版规划，实施前按格式扩展重新评估。视频制作单：封面、分镜序号、起止时间、画面、屏幕文字、口播、音效/音乐、引用资产、预计时长。分镜不可出现负时长；重叠必须标明叠加轨用途。字幕与口播可单独下载；首版不提供时间线剪辑。

提交审核必须有可预览成品、封面、标题正文；视频须有最终视频文件，图文须有有序页面。音乐/配音来源及允许使用范围记录在交付项中。内部审核结论绑定成品版本；替换视频、字幕、页面、文案会使旧审核失效。

## 素材详情页

左侧大预览；右侧名称、版本、标签、使用范围、下载与加入制作单；下方“版本历史 / 来源与衍生 / 使用记录”。本版详情展示PNG预览；品牌规范另有PDF分页与文本阅读入口。工程原件和转台视频详情为下版目标。用量统计按内容引用去重，不能把一次下载当成已发布。

## 验收要点

首版验证真实PNG（包含透明通道场景）和已有约410 MB、37页规范PDF；真实源素材与合成透明夹具必须分别说明。核验续传、原件哈希、中文名、停用/旧引用、替换版本、解析失败、权限/越限，以及不支持格式的拒绝。PDF另验分页/文本、规则页序边界与人工激活留痕。PSD、3D工程、MOV、长视频及音频矩阵移到下版，不作为当前S2阻塞；缺样本的下版格式不宣称兼容。
