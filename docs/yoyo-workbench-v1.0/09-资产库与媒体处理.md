# 09 · IP 资产库与媒体处理

v1.0｜2026-10-06。对应 R05、R06、R10、R11。资产库管理可复用的官方素材，成品归档记录实际发布版本；二者通过引用关联。

## 文件能力矩阵

以下为首版建议支持范围，需要用团队真实文件完成验收。识别类型同时检查扩展名、MIME 与文件内容，不能仅按后缀执行解析。

| 类别 | 原件保存 | 首版预览 | 不支持预览时 |
|---|---|---|---|
| 规范 | PDF | 分页缩略图、页码、文本检索 | 下载原件，提示解析失败 |
| 2D 图片 | PNG、JPEG、WebP、SVG | 栅格缩略图；SVG 安全转换后展示 | 保留原件和上传的预览图 |
| 2D 工程 | PSD、AI、其他设计工程 | 用户配套导出的 PNG/JPEG/PDF | 显示格式图标和“需源软件打开” |
| 3D 工程 | BLEND、C4D、FBX、OBJ、GLB、ZIP 等 | 首版使用关联渲染图/转台视频 | 不承诺在线编辑或任意格式 3D 预览 |
| 视频/动效 | MP4、MOV、WebM、GIF | 兼容的视频代理文件、封面、时长、尺寸 | 下载原件；转码失败可换传代理文件 |
| 音频 | WAV、MP3、M4A | 兼容播放器、时长 | 下载原件，显示编码说明 |

原件不因转码覆盖；代理文件仅用于播放。发布包始终明确“原始成品”或“平台导出版本”，禁止误用低清预览。

## 上传与处理

1. 创建上传会话，返回容量上限、分片大小、过期时间和会话 ID。建议单文件上限 2 GB，可配置；官方约 410 MB 的 PDF 必须实际测试。
2. 分片断点续传；重复分片幂等。完成后校验实际字节数、哈希和文件类型；失败不能创建可用资产。
3. 原件写入私有存储，生成 FileObject；异步生成缩略图、代理视频、元数据。界面分别显示原件上传和预览处理进度。
4. 同一工作空间哈希相同提示重复，可复用 FileObject；不同业务资产仍可各有记录。禁止通过去重接口泄露其他空间文件存在性。
5. 不认识的工程格式允许作为不可执行原件归档，不能因此卡住整个资产库。压缩包首版不自动展开引用路径；需展开时采用隔离处理并限制数量和解压体积。

上传取消清理未完成分片；已成功文件按引用清理策略处理。网络重连后查询服务器分片清单，不能重新上传整个视频。预览失败不等于原件丢失，也不等于资产不可用。

## 元数据与版本

必填：名称、类别、来源、所属系列、负责人、使用状态。可选：表情、动作、场景、配色、节庆、适用形式、标签、关联规范版本、使用范围、授权有效期、来源工程、关联渲染图。

媒体自动提取：尺寸、时长、帧率、音轨、编码、文件大小；提取失败显示未知。AI 标签仅为建议，确认后入正式字段。素材预览上直接区分 2D、3D 源文件、渲染图、视频和音频。

每次更新新建 AssetVersion。内容绑定具体版本；旧帖仍引用旧版本。退休素材不得加入新制作单，已有历史引用可读并提示状态。使用范围未确认的素材可以进入草稿，提交内部审核前必须确认或移除。新规则激活不自动判定历史帖子违规。

## 图文与视频制作交付

图文制作单：封面方向、逐页目的和文案、所需素材、画幅、交付清单。建议模板默认竖版 3:4；这是工作台模板建议，发布限制以当时平台确认结果为准。

视频制作单：封面、分镜序号、起止时间、画面、屏幕文字、口播、音效/音乐、引用资产、预计时长。分镜不可出现负时长；重叠必须标明叠加轨用途。字幕与口播可单独下载；首版不提供时间线剪辑。

提交审核必须有可预览成品、封面、标题正文；视频须有最终视频文件，图文须有有序页面。音乐/配音来源及允许使用范围记录在交付项中。内部审核结论绑定成品版本；替换视频、字幕、页面、文案会使旧审核失效。

## 素材详情页

左侧大预览；右侧名称、版本、标签、使用范围、下载与加入制作单；下方“版本历史 / 来源与衍生 / 使用记录”。3D 详情可同时展示工程文件、渲染图和转台视频。用量统计按内容引用去重，不能把一次下载当成已发布。

## 验收要点

至少用透明 PNG、PSD＋预览、3D 工程＋渲染、含音轨 MOV、长视频、410 MB 规范 PDF 各一件。验证断网恢复、原件哈希、中文文件名、退休资产旧引用、替换版本、预览失败下载原件、越权签名地址与超限提示。真实样本缺失项必须写进验收缺口。
