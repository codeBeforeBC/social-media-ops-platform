# 09 原IP资产库与内容媒体模块取消说明

v1.2｜2026-10-09｜[CHANGE-008 / ADR-008](../decisions/ADR-008-删除排期日历与活动.md)。本文件保留原路径以免历史链接失效；不再定义资产功能或下版格式扩展。

## 取消范围

R10/R11/R17及R05–R07全部退出（CHANGE-007）：PNG/工程/音视频素材上传、目录/标签/收藏、预览/版本/确认/退休、来源衍生/双向引用、品牌规范PDF/规则激活、语义检索/视觉检查；图文/视频制作单、逐页/分镜、成品上传/播放器、内部审核、发布包和成品归档。

日历/活动的追加取消边界见[11](11-排期与开奖提醒.md)。

原CHANGE-002的“PNG首版、其他格式下版”和CHANGE-004的视频文件恢复规划由本变更覆盖，不能继续实施或视作待完成范围。既有S2验收记录保留为历史投入，未完成S4/S5取消而不标通过。

## 保留的文件基础

后台截图/CSV/XLSX、来源证据仍需私有文件存储、会话/分片恢复、真实格式/大小校验、授权查看/下载、安全解析和引用清理。目的白名单与账号权限在S11-02收口，不提供素材目录、通用上传库、品牌PDF或成品入口。

删除专用PNG缩略图、手册分页、素材标签和ZIP导出代码前，先迁移Files中的权限及exportGuard耦合，明确导入截图/OCR和表格解析的运行资源。现有media执行器是否保留部分图片安全解析由实际调用决定，不能删除保护后直接在API无隔离解析文件。

## 数据退出

旧原件、版本、内容和发布包保存受限备份；历史记录不再暴露于新产品入口。Publication身份、实际时间和账号从旧内容关系迁出并保留ID。引用扫描覆盖来源、导入、审计/任务结果，不因文件曾用于资产而删除仍被保留业务使用的对象。

不能直接删除迁移005–008/015–024；它们含保留对象的基础、函数与外键。保留旧迁移，新增兼容迁移并演练，物理表/对象清理在核对备份与引用后执行，详见ADR-007/008。
