日期：2026-10-06。状态：**可用于开发评审、估时与分工的需求基线；尚未实现、联调或上线。**

本包整合用户已确认的产品范围与高保真界面。开发无需从对话、v0.1、v0.2、v0.3 文档中自行拼接需求。遇到冲突时，以用户后续明确要求和本包为准；旧效果图中的“任务书”统一替换为“内容制作单”，不增加独立外部品牌审批。

## 一句话需求

为携程旅行精灵 YOYO 的小红书账号提供内部运营工作台：AI 自动收集热点及优质内容、推荐选题、生成图文或视频内容制作单、辅助排期和复盘；团队负责实际设计制作、内部审核、人工发布与开奖处理。首要业务目标是涨粉，数据与结论必须可追溯。

## 已确认的开发边界

- 自动采集为首版核心需求，不能用手工导入参考替代完整验收。
- 审核在用户团队内部完成；AI 不自行审核通过。
- 内容支持图文与视频，资产支持规范、2D、3D 源文件、渲染图、视频动效、音频。
- 日历含制作、内部审核、发布、数据回收及开奖提醒；开奖处理仍由人完成。
- 账号后台数据首版支持截图识别＋表格导入＋人工修正；全量自动同步待权限验证。
- 首版不实现自动发布、批量互动、投流、自动抽奖、网页剪辑器或 3D 编辑器。
- 本包不包含网站源代码、数据库脚本、真实 API 凭据、实际采集结果或真实自动化任务。

## 版本和证据原则

“已确认”指用户明确表达的产品要求。“建议默认”用于让开发可以估时、搭建和试跑，不代表用户承诺的预算或产能。“待验证”是外部事实或样本依赖，由指定负责人收集证据后关闭。

界面示意中的素材、任务、活动、发布日期不是生产种子数据。截图中的 631 粉丝、1,579 获赞与收藏只属于 2026-10-03 的历史观察值。任何 demo 数据必须隔离于生产。
