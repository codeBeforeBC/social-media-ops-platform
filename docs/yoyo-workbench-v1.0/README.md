## 当前边界

- 全部 IP 资产库功能取消，包括上传/目录/标签/收藏、版本/引用、品牌规范PDF管理和规则激活、高级资产检索；取消而非延期。
- 全部内容工作间功能取消，包括图文/视频制作单、编辑/成品上传/预览、类型转换、内容版本、内部审核、辅助检查、发布包、修订工作项和成品归档；不在其他页面恢复这些能力。
- 选题采纳只保存决策和负责人，不创建 Content、修订或制作单任务。AI 不依赖素材或品牌规范库。
- 全部排期日历与活动取消，含AI排期、开奖/公告/提醒、活动标记和自动数据回收节点；不转入其他页面实施。
- 已发布笔记最小登记作为数据复盘的身份信息：账号、笔记ID/链接、标题、形式、实际时间、流量类型；不管理正文、成品或审核版本。
- 上传仅服务于后台截图/表格、来源证据，不提供通用素材管理入口。文件基础、安全校验与权限不能随资产页面一起删除。
- 保留三类定时自动来源、通用系统通知、指标溯源及反馈许可；不自动发帖、开奖或发送回复。

本轮更新的是设计和清退方案，现有代码仍含被取消模块。旧契约、迁移、测试、证据、图及手册保留历史记录，不作为新范围验收通过证据。后续实际清退需通过 T25/T26；详见[实施计划](../开发实施计划-v1.0.md)。
