## 建议默认值（可评审调整）

| 项目 | 当前基线 | 调整影响 |
|---|---|---|
| 组织 | 单工作空间、单小红书账号，约 5 人协作 | 多组织需补隔离及计费/管理设计 |
| 来源频率 | 每日 09:00、16:00，手动触发可加入任务 | 依供应限制与成本调整 |
| 提醒 | 前 1 天、前 1 小时、到点站内提醒 | 离站触达需追加通道 |
| 文件上限 | 2 GB，分片续传 | 用真实工程文件验证成本与带宽 |
| 内容回收 | 发布后 24 小时及 7 天 | 有数据才算；调整不造历史观察 |
| 页面视觉 | 白底、蓝色强调、清晰表格与内容卡片 | 见参考图；界面颜色不等于改 IP 本体色 |
| 增长目标 | 先建立基线，再由负责人定目标 | 无“保证涨粉”承诺 |

## IP 与历史资料使用

当前参考手册封面版本为 06/2026；账号截图属于 2026-10-03 历史观察，不能代表今天粉丝数。官方主色参考页为 PDF 第 17 页：#319AFF，辅助蓝 #2582E6；肤色 #FFEAE0、腮红 #FFC6BA。项目实际使用时对照原始手册色彩空间和源文件，不从屏摄取色。

角色设定、官方造型、比例和颜色属于规范约束；新增世界观、栏目及表达方式作为策划建议，不能自动升级成官方设定。界面中的手绘、毛绒、3D 形象必须来自相应已确认资产，不能把生成效果图内人物当成最终素材。
