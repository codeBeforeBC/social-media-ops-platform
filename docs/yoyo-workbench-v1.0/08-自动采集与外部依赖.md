# 08 自动采集与外部依赖

v1.2｜2026-10-09。来源能力要求延续；实际接入与验证事实见开发进度和S3证据，不由本规格推定。CHANGE-007/008不取消三类来源；来源schedule、定时采集和失败恢复继续保留，与取消的运营排期日历无关。

## 1. 接入目标与验收边界

| 来源 | 产品需求 | 开工证据 |
|---|---|---|
| 微博热点 | 定时获取真实可用榜单/话题，带名称、时间、原始链接 | 一个当前真实响应或授权读取样本、可用字段、范围和刷新限制 |
| 小红书热点 | 获取真实可用的榜单或话题信号，按实际来源命名 | 证明该源是官方榜、话题页、搜索还是供应商自建榜 |
| 小红书优质笔记 | 基于旅行/IP/潮玩/情绪等关键词和参考账号获取允许读取的内容 | 笔记原文/摘要、作者标识、时间、可见互动、分页和详情能力样本 |

手工粘贴链接可用于测试和救急，不是 R03 完整验收替代。三类来源任一不能接入时，应记录缺口、替代来源与影响，由产品负责人明确接受范围变更后方可改变首版验收；不能用假结果上线。部分来源接通可以进行内部试跑，必须显示具体覆盖范围。

## 2. 来源选择程序

优先评估实际可用的正式接口或获得相应权限的数据服务；若采用授权浏览器读取，明确运行机器、会话归属、可读范围、人工登录恢复方式和稳定性。不得假定拥有未确认的接口，不把逆向绕过限制作为必要实现步骤。遇到登录、验证码或访问拒绝，停止相应源并显示需人工恢复，避免无休止请求。

采集方案评审必须填写：提供方/实际接口或页面、授权/合同范围、字段样例、可允许保存内容、账号要求、频率、配额、费用、运维责任、失败特征、替代方案。只说“能爬”不通过评审。

小红书创作服务平台公开介绍有数据分析，但不能据此断言自然账号数据均有开放 API；Marketing API 公开说明面向投放相关能力。背景链接：[创作服务平台](https://creator.xiaohongshu.com/)、[开放平台](https://ad-market.xiaohongshu.com/)。这些链接不是本项目已验证的数据接口。

## 3. 统一适配器能力

每个连接上报 capabilities：list_items、read_detail、read_comments、historical_metrics、own_account_metrics 等独立布尔能力，未知与不支持分开。连接 health：unverified/healthy/degraded/auth_required/rate_limited/unavailable/disabled。

输入：连接、时间范围、关键词/参考账号、有界分页、上次游标、运行预算。输出：items、next_cursor、captured_at、coverage、warnings、quota_state。错误按 AUTH_REQUIRED、RATE_LIMITED、ACCESS_DENIED、SOURCE_CHANGED、TIMEOUT、PARSE_FAILED 标准化，原始响应只在受限日志保存必要片段。

每个 item 必须有稳定外部 ID 或规范 URL、实际来源类型、标题/摘要、采集时间和证据；发表时间、排名、互动取不到则 null。保留原始链接的访问参数但限制展示敏感令牌，日志脱敏。不得将采集时间写成发布时间。

## 4. 自动运行与时效

建议默认每天09:00/16:00（Asia/Shanghai），由每源限制覆盖；“立即刷新”亦受相同限制。同源只允许一个运行；部分失败保留已成功条目但批次为 partial。连接连续失败建议3次后暂停自动重试并通知管理员；恢复后先做一次验证。

热点初始有效期建议24小时，具体事件可人工修改；常青笔记不按24小时删除，但需显示来源年龄。过期条目保留用于溯源，不再标“当前热点”。只有两个可比观察点才计算互动变化；只抓一次时不描述增长速度。

采集预算建议每源每次先取前50条以内的可用线索，分页和详情请求额度由来源限制与成本设置共同约束，不做全量无限抓取。历史补抓与日常刷新分任务，以免影响时效。

## 5. 去重、筛选和优质参考

同源用 external_id 去重；无 ID 时规范 URL＋内容指纹。跨源相似内容进同主题 cluster，保留各原始来源与观察值。不要因为标题相似就合并不同事件或话题。

筛选分三步：旅行/IP需求相关性；内容结构、事实与画面价值；YOYO 可原创表达和制作可行性。热门与优质是不同标签。互动数量是参考信号，不能把公开点赞当阅读率，也不能从热门直接推出涨粉有效。

引用范围明确：保存必要摘要、来源与可用证据；外部图片/视频默认 reference_only，仅作外部研究参考，不转入素材库或成品工作流。系统只提供选题依据，实际制作/发布在系统外完成。

## 6. 接入验证报告模板

每源保存一份报告，字段为：测试日期、提供方、操作者、授权范围、真实样本位置、成功字段、缺失字段、请求频率、耗时、是否需交互登录、连续多次成功情况、失败与恢复试验、费用、结论。至少覆盖成功、限流/超时、会话失效、字段变化四类试验；不可在生产故意触发攻击，只在可控测试或模拟适配器验证失败逻辑。

验收证据需证明日常运行不要求用户每次提交参考；某源无法获取时，页面状态与任务日志能准确说明。来源关闭/删改后，已采纳选题保留来源记录并显示不可访问，不能伪造已验证原文。
