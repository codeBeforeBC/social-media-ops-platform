# 01 产品需求 PRD

v1.2｜2026-10-09｜[CHANGE-008](../decisions/ADR-008-删除排期日历与活动.md)。需求编号永久保留，取消项不重新编号。

## 1. 目标与用户

服务 YOYO 小红书账号的运营研究、选题和数据复盘。视觉创作、视频剪辑、内容确认及平台发布在系统外完成。主目标仍是持续且符合定位的关注；周净增粉与28日趋势必须来自实际可比数据，软件验收不保证涨粉。

首版一个工作区、一个小红书账号，保留 workspace_id/account_id 隔离。各本地实例实际使用者承担业务负责人职责，可兼任多个角色；不要求单人另配备用人。

## 2. 业务闭环

配置账号 → 自动采集 → AI 推荐选题 → 人采纳/驳回 → 系统外制作并人工发布 → 登记已发布笔记 → 导入后台数据并确认 → 计算指标与 AI 复盘 → 人采纳下一轮策略。

排期日历、活动、开奖/公告登记及相关提醒全部取消；不以普通事项、待办或新表单重建这些业务。来源定时采集和系统任务通知继续保留。

## 4. 关键约束

AI最多6候选为建议默认，可提供不足数量的明确结果。没有来源的常青题标 original_hypothesis，不伪造热点、来信、价格、旅行经历或增长效果。栏目及表达定位作为运营策略，不建设品牌规则库或素材选择器。

已发布笔记登记属于 R12/R13 的数据身份基础：真实平台ID、账号、链接、实际发布时间必需；标题/形式/流量类型用于分析，不保存活动标记。缺ID保持表单未提交，不建设发布暂存工作流。重复ID拒绝或返回同一记录；外部删除标记保留指标，重发新ID另登记。系统不证明外部笔记内容经过内部审核。

实际发布时间只作为数据身份和分析窗口的依据；登记不产生排期、回收节点或定时提醒。后台样本缺失仍阻塞真实OCR及口径验收，不阻塞手工/表格开发。

移除全部内容编辑、成品文件、审核与归档入口。导入与来源证据不是可复用资产，不能用新名称重建被取消模块。

## 5. 体验与业务评估

中文优先、键盘可操作、主要任务两级内到达；数据不足显示缺项与处理入口，不造趋势。未知与0分开，示意数据与真实数据隔离。

试用观察来源稳定性、采纳决策完成、数据完整率和实际反馈；不再以素材复用、内部审核完成率或采纳到成品时间作为产品必需指标。制作工时仅在使用者手工提供时参与可选分析。
