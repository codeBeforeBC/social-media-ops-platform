# 10 · 后台数据导入与指标口径

v1.2｜2026-10-09。对应 R12、R13；CHANGE-007/008保留数据能力，移除对内容工作间、日历与活动的依赖。截图可以使用，但必须是能够看清指标名、日期范围、账号或笔记身份的后台截图。已有公开主页截图只能记录公开观察值。

## 独立笔记匹配与文件边界

单篇数据直接以account_id＋platform_note_id匹配独立Publication。没有内部制作稿、素材或批准版本也能登记和导入；未匹配笔记先人工登记，不猜测身份。笔记形式仍为graphic/video，用于分析已有外部视频，不代表提供视频制作或成片管理。发布时间更正留审计并重验分析窗口/报告，删除外部笔记不删除历史指标。

截图与CSV/XLSX按导入目的上传，保留私有存储和安全解析；不接受品牌手册、素材/成品管理。真实格式和限额在S11-02/S7验证。表格/手工确认可独立于OCR开发；最终真实OCR门禁仍需后台样本。

## 用户需要提供什么

| 数据 | 推荐输入 | 缺失时如何处理 |
|---|---|---|
| 账号表现 | 创作者后台账号概览，含日期范围、粉丝、新增/流失等实际显示字段 | 可人工填写；不猜测不存在的字段 |
| 单篇表现 | 单篇后台，含笔记标识、阅读/播放、互动及平台实际提供的其他字段 | 用户选择对应已发布笔记；身份不清不得直接确认 |
| 视频表现 | 实际显示的视频分析页，如观看时长、完播率 | 无字段则“未提供”，不从点赞推算 |
| 批量数据 | 后台可导出的表格；或本系统模板 | 导出功能是否可用需实际确认 |

同一批允许多张截图拼接，但不能因此重复累加。上传前页面给出示例提示：保留指标标签与日期，不需要密码、验证码或个人私信。原截图只供授权内部人员核对。

## 导入流程

上传 → OCR/表格解析 → 字段映射 → 对照原图预览 → 处理未知、冲突与重复 → 人工确认 → 原子入账 → 生成可追溯报告。

确认页每行显示：账号、笔记、指标、值、单位、统计窗口、观察时间、来源区域、置信度、重复判断。低置信值高亮，不能自动确认。用户修改保留原始识别值与更正记录。“1.2 万”保留原文、解析值 12000 和 approximate=true，不伪装成精确计数。

表格模板字段：account_id、platform_note_id（账号指标可空）、metric_key、value、unit、window_start、window_end、observed_at、traffic_type、source_note。模板下载时带中文说明和示例行；示例行必须明确且不可入账。

批次确认可排除部分行。整个提交失败不得出现界面失败但半批无记录入账；允许用户显式选择部分有效行，状态为 partially_confirmed。每行永久保存来源与确认人。

## 唯一性、冲突与撤销

逻辑键：工作空间＋账号＋指标主体（账号或笔记）＋metric_key＋definition_version＋统计类型＋流量类型＋统计窗口（区间）或 observed_at（快照/累计）。时间精度取来源实际粒度，不捏造秒级时间。

同逻辑键同值视为同一观察，可增加来源证明而不重复统计；同键异值进入冲突确认，用户选择保留旧值或以新值取代，旧记录标为 superseded。不同观察时点的累计值属于不同快照，不能相加。批次文件哈希只能识别完全重复文件，不能替代业务去重。

撤销批次使该批新增观察失效；只由该批取代的旧观察可恢复。若后续批次又确认了更新值，不得撤销后续结果；共享观察还有其他有效来源时仍保留。所有依赖被撤销数据的报告标记 stale，重新计算后才恢复可用。删除截图不应默默删除已确认指标，使用单独撤销动作。

## 指标字典与公式

| 指标 | 单位 / 类型 | 计算规则与限制 |
|---|---|---|
| 粉丝总数 | 人 / 快照 | 指定时点值，不跨日求和 |
| 净增粉 | 人 / 区间 | 同口径期末粉丝−期初粉丝；缺任一端则空 |
| 新增关注、取关 | 人 / 区间 | 仅来自后台实际字段；净增不能反推出两者 |
| 曝光、阅读、播放 | 次 / 累计或区间 | 三个不同指标，不混为统一浏览量；保留平台定义 |
| 点赞、收藏、评论、分享 | 次 / 累计或区间 | 按对应指标分别保存；重复快照不累加 |
| 笔记归因新增关注 | 人 / 累计或区间 | 仅后台明确归因字段；不能按互动分摊账号涨粉 |
| 千次阅读带来关注 | 人/千次 / 派生 | 同笔记同窗口归因关注÷阅读×1000；缺值或分母为 0 则空 |
| 互动次数率 | % / 派生 | 同窗口(赞＋藏＋评＋分享)÷阅读×100%；不是独立互动人数率，可能超过 100% |
| 完播率、平均观看时长 | %、秒 / 平台字段 | 原样保留口径；跨笔记汇总须有对应分母/权重，否则不算总体值 |
| 单位制作时间增粉 | 人/小时 / 派生 | 仅在使用者另外提供真实工时且有归因关注时可选计算；不从内容工作间继承，不计首版必需指标，也不是因果效果 |

派生值记录 calculation_version、输入观察 ID、窗口与舍入规则。展示计数整数，百分比默认两位小数，计算内部不提前舍入。source_definition 不一致时分组展示，不强行对比。

## 分析边界

按同样发布后时长比较（如 24 小时或 7 天）是建议分析视角，只有具备对应观察才可使用。不可把发布一天的数据与发布一个月的数据直接排名为“内容质量”。自然、付费、混合、未知流量分开；不保留活动标记、活动筛选或分组。24小时/7天仅为实际数据的可选比较窗口，不生成日历节点、定时回收或提醒。

“获赞与收藏 1579”是组合公开字段，不能拆成点赞和收藏。631 粉丝只是一条历史快照，没有期初就没有净增。无归因关注时允许用阅读、收藏等做代理观察，必须明确“尚不能判断涨粉贡献”。

AI 报告按“已知事实 / 可能原因 / 下次实验 / 缺失数据”输出。事实数字来自后端计算，建议可被用户采纳为新选题；不会自动激活策略记忆，也不提供排期建议。
