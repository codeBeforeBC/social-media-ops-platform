## 运维与交接

提醒独立池/服务/诊断退出；沿用Web/API、worker、来源/Job scheduler、数据库、私有存储。移除专用素材/手册/ZIP执行资源前核对导入OCR/图片/表格是否仍使用解析隔离环境。配置记录来源频率/凭据位置、AI/OCR、文件限额/签名TTL、任务并发、时区、日志/预算/备份；无密钥、cookie或签名URL。

各实例实际使用者为业务/运行负责人，单人不要求备用人；多人有替代值守时登记移交。来源失败只暂停该源；任务失败按保留业务重试；AI故障不影响登记和手工导入。导入错误走批次撤销，不手改数据掩盖。

RPO≤24小时/RTO≤4小时为待实测目标。数据库、证据文件和实例凭据同恢复点；检查Publication身份、来源/决策、指标更正链及任务有效性，不照搬旧队列盲发。已有迁移不改写，兼容升级与回滚实测；有损清理先备份/引用报告后执行，不做DROP CASCADE或删除持久卷。

交付源码/锁文件、实际接口与迁移、脱敏来源/后台映射报告、AI评估、迁移/恢复证据、运行说明与已知限制。试用观察来源、选题采纳、反馈和数据完整性，不再要求素材复用或内部制作产能数据。
