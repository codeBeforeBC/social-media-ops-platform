# 06 内部接口契约

v1.0｜2026-10-06。以下为本项目内部 HTTP 契约提案，不是小红书或微博官方 API，也不表示已实现。数据字段及枚举见 05/03；技术评审后可转换成 OpenAPI 文档。

## 1. 通用协议

前缀 /api/v1，认证由内部登录会话承担；所有接口验证工作区成员权限。工作区由会话与显式 workspace_id 共同校验，不仅相信客户端提供的 ID。Cookie 会话需防 CSRF；下载为有权限的临时签名 URL。

成功响应：data＋meta，其中 meta 含 request_id、server_time；列表含 items、next_cursor。错误响应：error.code、message、field_errors、retryable、request_id。服务端时间 ISO8601 UTC，显示时区另外传递。

列表参数 cursor、limit（默认20，最大100）、sort、filters；支持更新时间和 ID 的稳定排序。时间过滤 start 含/end 不含。字符串去除非法控制字符，不静默截断正文。

写操作带 Idempotency-Key（创建、采纳、确认、发布、开奖、导入确认均必需），修改带 expected_version。相同键相同请求返回原结果；相同键不同请求返回 409 IDEMPOTENCY_CONFLICT。业务唯一性不依赖短期缓存失效；结果映射建议保留 30 天。版本冲突返回 409 VERSION_CONFLICT 与最新 version，不自动覆盖。

新建成功 201，同步更新 200，异步受理 202＋job_id＋status_url。422 为字段/业务守卫失败；401 未登录，403 无权限，404 不存在或不可见，429 限流，503 外部不可用。关键错误码：REVIEW_STALE、ASSET_UNUSABLE、DEPENDENCY_CONFLICT、SOURCE_UNVERIFIED、DATA_SCOPE_MISMATCH、METRIC_DUPLICATE、CAMPAIGN_TIME_INVALID、BUDGET_EXCEEDED。

## 5. 资产、规范和文件

当前写入范围按[CHANGE-002 / ADR-004](../decisions/ADR-004-S2首版PNG素材范围.md)：上传purpose=asset只接受PNG，purpose=guideline只接受PDF；校验扩展名、MIME与内容。Asset类别仅2d/render；PDF通过独立规范接口管理，不能作为普通素材创建。其他文件格式及视频clip_range首版拒绝，宽枚举中的其他值仅保留历史样例/后续扩展，不代表可写。规范规则source_page按PDF页序校验，激活仍需人工核对和留痕。

## 8. 必须演练的请求序列

路径展开约定：表中 GET/POST/PATCH 组合写法是阅读简写，GET 集合用于列表、POST 集合用于创建、PATCH 必须落到 /资源/{id}；详情 GET /资源/{id} 返回实体、version 和允许操作。适用于 members、assets、feedback、folders、calendar-events、campaigns。认证会话由选定登录提供方建立与注销，不以此文捏造企业 SSO 接口；D01 必须补实际登录/退出/过期协议。

补充动作：POST /contents/{id}/start-production（expected_version）进入制作；POST /contents/{id}/create-revision-work-item（owner_id、reason、expected_version）仅对已发布内容创建带 supersedes_content_id 的修订工作项。POST /publications/{id}/changes 的 edited 必须引用该笔记关联修订工作项的批准版本；事务内更新 current_revision_id、记录变更并将修订工作项置为 published。活动管理员纠错使用 POST /campaigns/{id}/correct-state，必须带 target_state、reason、evidence、expected_version，按新版本重算提醒并保留审计。

手工新增指标走 POST /imports 的 source_type=manual、file_ids 可空，后续使用相同确认/冲突流程；文件导入必须非空。GET /imports/template 返回当前字段模板和版本。GET /rule-sets/{id}、GET /campaigns/{id}、GET /publications/{id}、GET /assets/{id} 应返回对应详情及引用，不能依赖列表缓存拼接详情。

选题采纳返回 content_id 后，生成任务失败再重试仍写入同一内容；内容 v3 提审后用户编辑 v4，审批 v3 返回 REVIEW_STALE；同笔记相同数据确认重试只保留一份；活动 v2 改开奖时间后 v1 worker 到期必须无副作用结束。前后端用这些序列契约联测，不能只测试 happy path 的 200 响应。
