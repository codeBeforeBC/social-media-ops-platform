# 06 内部接口契约

v1.2｜2026-10-09。以下为删减后的目标协议；当前代码及contracts JSON尚未切换，不能宣称这些调整已实现。S0-08负责生成源/样例/JSON同步，清退验证见T25/T26。[依据](../decisions/ADR-007-删除IP资产库与内容工作间.md)。

## 1. 公共协议

/api/v1，内部会话、CSRF、工作区及账号权限校验。成功data＋meta(request_id/server_time)，列表items/next_cursor；错误code/message/field_errors/retryable/request_id。分页默认20最大100，时间start含/end不含。

写操作Idempotency-Key；修改expected_version。相同键相同载荷复用，异载荷409；业务唯一键独立存在。版本冲突409，不静默覆盖。201创建，200更新，202异步job_id/status_url；401/403/404/422/429/503维持公共约定。保留DEPENDENCY_CONFLICT、DATA_SCOPE_MISMATCH、METRIC_DUPLICATE、BUDGET_EXCEEDED；退出CAMPAIGN_TIME_INVALID及REVIEW_STALE/ASSET_UNUSABLE等取消模块专用错误。

## 2. 账号与运行

保留实际首次设置/登录/退出/邀请/过期协议、GET /me、GET/POST /accounts、GET/PATCH /accounts/{id}、GET/PATCH /settings、GET/POST /members、PATCH /members/{id}、GET /dashboard、GET /audit-logs、GET /jobs、GET /jobs/{id}及cancel/retry、GET /monitor。角色/权限按03迁移；不能仅移除前端菜单。

## 3. 来源与选题

| 方法/路径 | 输入与结果 |
|---|---|
| GET/POST /source-connections，GET/PATCH /source-connections/{id} | 提供方、能力、计划、credential_ref、enabled、version；未知健康不叫已连接 |
| POST /source-connections/{id}/verify或refresh或pause | 有界范围/原因，202任务；同源复用、限流与暂停 |
| GET /source-connections/{id}/runs，GET /source-items，GET /source-items/{id} | 覆盖、原文/时间/类型、不可变观察和局限 |
| POST /topic-generations | account_id、window、columns、capacity_hours?；202；不接收/读取素材或规范ID |
| GET /topics，GET /topics/{id} | 保留筛选/证据/决策，不返回素材资源、内容/制作单跳转 |
| POST /topics/{id}/accept | owner_id?、expected_version；200 decision_id/topic_id/status/version，重复采纳同一结果，不创建内容或Job |
| POST /topics/{id}/reject | reason、expected_version；保留原因 |
| POST /topics/{id}/variants | goal、media_type；独立候选及parent_topic_id，不创建制作稿 |
| GET /ai-requests/{id} | 已授权任务状态与保留结果；旧生产结果仅历史，不提供采用动作 |

建议图文/视频形式仍是选题分析字段；采纳不要求制作单类型参数。新旧accept响应为破坏性变化，前后端、测试、脚本和契约同一版本切换，旧幂等结果按作用域/版本处理，避免新调用获得旧content_id。

## 4. 独立笔记与反馈

| 方法/路径 | 输入与守卫 |
|---|---|
| GET /publications，GET /publications/{id} | account_id、media_type、lifecycle等筛选；返回身份/时间/分析标记，不返回制作版本和成品 |
| POST /publications | account_id、platform_note_id、url、title、media_type、published_at、traffic_type；无需批准版本，无活动标记；不创建回收/排期/提醒Outbox |
| PATCH /publications/{id} | 允许的标题/分析标记/lifecycle、reason、expected_version；不能换账号/平台ID挪用历史指标，发布时间更正重验分析窗口/报告并留痕 |
| GET/POST /feedback，GET/PATCH /feedback/{id} | publication_id?、source/text/consent/reply_draft、version；无发送接口 |

ID与链接校验同一笔记且实际时间不在未来；重复(account,platform_note_id)返回冲突或幂等原记录。缺ID请求422，不保留发布暂存接口。修改标题是登记元数据纠正，不是编辑外部正文。

## 5. 导入文件与数据

复用POST /uploads、GET /uploads/{id}、分片/complete/abort及GET /files/{id}/download或preview；purpose仅import_screenshot/import_table/source_evidence，显式account_id或已授权引用对象。上传、下载权限改为保留业务动作；拒绝旧asset/guideline/成品及campaign_evidence用途，无法凭通用文件ID下载退出模块原件。扩展名/MIME/内容/大小一致性、私有签名、恢复和安全解析保留。

| 方法/路径 | 输入与结果 |
|---|---|
| POST /imports，GET /imports/{id}，GET /imports/{id}/rows | account_id、file_ids、source_type；异步解析与原图/原值/置信；manual可无文件 |
| GET /imports/template | 字段版本、中文说明及明确不可入账的示例 |
| PATCH /import-rows/{id} | 目标、指标、值/单位、窗口/观察时间、状态、expected_version；纠正不直接入账 |
| POST /imports/{id}/confirm或revert | 所选行/冲突解决/原因、version；原子入账或撤销，更正链和报告stale |
| GET /metrics | account/publication、window、media_type、traffic_type；来源/口径/缺失/计算版本 |
| POST /reports，GET /reports/{id} | 程序先计算、AI解释；partial/final/stale |
| POST /reports/{id}/accept-actions，POST /strategy-memories/{id}/activate | 人工确认行动/策略；不产生制作单或品牌规则 |

## 6. 通用通知

GET /notifications和POST /notifications/{id}/read按个人隔离，只记已读；保留来源异常、异步任务、导入和报告的结果/失败通知。无日历事项、活动/开奖和定时业务提醒接口。来源连接的schedule是自动采集配置，继续保留。

## 7. 退出端点与联测

完全移除 /calendar-events、/campaigns、/schedule-proposals及全部子动作，不继续实现原planned接口；提醒池诊断退出。完全移除 /contents及其所有子动作、/content-revisions、/reviews、/export-packages、/publication-drafts、/publications/{id}/changes生产修订接口、/assets、/asset-versions、/asset-relations、/asset-usages、/folders、/guideline-files、/rule-sets及收藏/激活子动作。旧调用返回404或410，不执行任何创建/编辑/导出。source/feedback/Publication和导入文件端点保留，不按关键词content/file整组删除。

必须联测：重复采纳不出现Content/Job；零资产/规则库仍能推荐；无批准版本独立登记且跨账号拒绝；导入未匹配先登记再确认；笔记登记/更正不创建排期、回收或提醒；来源定时采集和通用任务恢复可用；旧制作/排期/活动/回收Job完成竞争无业务效果；旧链接/文件签名到期后不再可申请。历史签名有TTL窗口，清退需列清单处理，不宣称撤掉路由即撤回已签名URL。
