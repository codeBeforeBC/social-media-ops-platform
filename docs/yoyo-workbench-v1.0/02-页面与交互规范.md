v1.2｜2026-10-09｜以[CHANGE-008](../decisions/ADR-008-删除排期日历与活动.md)为准。旧效果图不能继续定义六导航或制作/资产/日历/活动操作。

## 1. 信息架构

主导航：工作台、选题策划、数据复盘。账号、通知、成员、来源和运行设置保留全局入口。已发布笔记列表/登记、数据导入、反馈放数据复盘内，不提供活动管理入口。

建议路径：/workspace、/topics、/analytics、/analytics/publications、/settings、/notifications。现有实现使用hash导航，清退时移除 #assets/#contents/#calendar，旧收藏地址进入工作台并提示模块已移除；服务端旧业务接口一并退出。

## 2. 页面规格

| 页面 | 展示和操作 | 关键状态 |
|---|---|---|
| 工作台 R02 | 有时间/来源的指标、最多3项优先任务、导入确认、来源异常、缺数据 | 真空态、历史数据、数据过期、服务异常；无制作待审 |

| 数据复盘 R12/R13/R15 | 账号/笔记指标、图文/视频/流量筛选、登记笔记、导入、周报与反馈 | 未匹配笔记、待确认、不可比、partial/stale报告 |

## 3. 操作规则

选题卡保留人群、证据/时间、原创角度、关注理由、建议形式、估时及不确定项。采纳选择负责人并记录决策，同一题重复操作返回同一决策。不创建内容、修订、制作单Job或日历事项。刷新保留历史决策，各来源独立展示失败。

登记已发布笔记：账号、平台ID、规范链接、标题、形式、实际发布时间、流量类型。未核对身份不能入正式统计；不选择批准版本，不上传成品，不提供发布包。外部已删笔记保留身份和历史数据；重发作为新ID。账号/ID更正需显式原因及审计，已有指标不能静默转移。

排期日历与活动详情、开奖/公告操作和相关提醒入口退出。旧深链返回工作台并说明模块已移除，旧通知操作链接失效。

导入：选账号/类型 → 截图或表格 → 异步解析 → 原始材料与提取表并排 → 匹配笔记和修正窗口/单位 → 确认有效行。未匹配可从此处登记笔记；低置信或冲突不得静默入账。反馈从笔记分析或独立反馈列表录入，许可与撤回可见。

## 4. 表单与异常

账号需平台/账号ID/名称/时区。不提供活动规则、计划时间或提醒表单。数据行需目标/指标/值或缺失/单位/窗口或观察时间/来源；计数非负，净增可负。

409显示最新版本和修改时间，允许重新确认；403/404不泄露资源存在性；异步失败保留输入，离线不显示保存成功。旧模块通知仅显示历史失效说明，不跳转已取消的制作/资产/日历/活动页面。

1440/1280桌面完整操作；窄屏保障待办、通知、导入确认和数据概览。状态有文字，键盘焦点明确，图表不以颜色独自表达。延用现有蓝白/中性灰界面和公共组件；不以新效果图替代实际可用性验证。
