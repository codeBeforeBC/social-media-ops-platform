# 02 页面与交互规范

v1.2｜2026-10-09｜以[CHANGE-008](../decisions/ADR-008-删除排期日历与活动.md)为准。旧效果图不能继续定义六导航或制作/资产/日历/活动操作。

## 1. 信息架构

主导航：工作台、选题策划、数据复盘。运营账号、通知、来源和运行设置保留全局入口。CHANGE-014删除工作台内部登录/退出、个人资料/角色/成员邀请及用户切换；启动直接进入工作台或显示实例初始化错误，参见[CHANGE-014免登录规划](../plans/CHANGE-014-本地单实例免登录规划.md)。已发布笔记列表/登记、数据导入、反馈放数据复盘内，不提供活动管理入口。

建议路径：/workspace、/topics、/analytics、/analytics/publications、/settings、/notifications。现有实现使用hash导航，清退时移除 #assets/#contents/#calendar，旧收藏地址进入工作台并提示模块已移除；服务端旧业务接口一并退出。

## 2. 页面规格

| 页面 | 展示和操作 | 关键状态 |
|---|---|---|
| 工作台 R02 | 有时间/来源的指标、最多3项优先任务、导入确认、来源异常、缺数据 | 真空态、历史数据、数据过期、服务异常；无制作待审 |

## 3. 操作规则

候选列表采用单列紧凑条目，常显完整标题、两行写作角度、状态/形式、去重参考来源及必要核验提示；默认待采纳，已有明确筛选与恢复状态优先。共用资料限制按真实生成批次集中折叠，不逐卡重复长待补、评分和未知工时；详情保留完整人群、场景、关注理由及核验信息。采纳自动使用实例默认用户并记录决策，不提供负责人选择；同一题重复操作返回同一决策。不创建内容、修订、制作单Job或日历事项。刷新保留历史决策，各来源独立展示失败。

选题详情按[CHANGE-019排版方案](../plans/CHANGE-019-选题详情阅读排版方案.md)组织为摘要、原创角度/人群需求/场景/关注理由、分类依据、使用前核对、折叠生成说明/评分与决策历史。仅该抽屉桌面加宽至840px、窄屏全宽，正文独立滚动，标题与底部操作保持可见。来源原文、AI推测、原创假设分开；风险不折叠，观察时间不当作发布时间。保留原采纳确认、拒绝原因和变体目标/形式；错误在抽屉内显示，版本冲突须读取最新选题再确认，失败保留填写内容，提交期间防止重复操作。该排版不增加AI调用、不改变03的状态和权限规则；实际实现/验收状态见开发进度。

登记已发布笔记：账号、平台ID、规范链接、标题、形式、实际发布时间、流量类型。未核对身份不能入正式统计；不选择批准版本，不上传成品，不提供发布包。外部已删笔记保留身份和历史数据；重发作为新ID。账号/ID更正需显式原因及审计，已有指标不能静默转移。

排期日历与活动详情、开奖/公告操作和相关提醒入口退出。旧深链返回工作台并说明模块已移除，旧通知操作链接失效。

导入：选账号/类型 → 截图或表格 → 异步解析 → 原始材料与提取表并排 → 匹配笔记和修正窗口/单位 → 确认有效行。未匹配可从此处登记笔记；低置信或冲突不得静默入账。反馈从笔记分析或独立反馈列表录入，许可与撤回可见。

来源采集提交后自动打开运行记录并展示真实任务阶段；排队/执行时自动刷新，完成/失败/取消后停止高频轮询，来源列表保留最新任务摘要，刷新页面仍可查。展示提交、开始、结束时间与实际排队/采集耗时，完成显示条数，失败显示错误；状态读取故障提示并可恢复，不将提交成功当执行完成，也不虚构百分比或队列名次。采集完成后按当前筛选刷新线索。

## 4. 表单与异常

账号新增固定小红书，输入完整官方主页链接或24位内部ID、本地备注名称和时区；服务端规范化为内部ID和去参数主页，拒绝昵称、小红书号、笔记链接及其他平台新增。保存后保留详情，明确“已保存、身份未验证”，保存不代表平台登录或采集可用；失败保留输入，重复身份可查看已有账号。详情完整显示只读内部ID、复制及按合法ID生成的主页入口；旧格式账号仍可编辑备注并显示核对提示。在线验证结果/按钮需后续独立接入，不能以只读探测报告代替产品状态。不提供活动规则、计划时间或提醒表单。数据行需目标/指标/值或缺失/单位/窗口或观察时间/来源；计数非负，净增可负。

409显示最新版本和修改时间，允许重新确认；403/404不泄露资源存在性；异步失败保留输入，离线不显示保存成功。旧模块通知仅显示历史失效说明，不跳转已取消的制作/资产/日历/活动页面。

1440/1280桌面完整操作；窄屏保障待办、通知、导入确认和数据概览。状态有文字，键盘焦点明确，图表不以颜色独自表达。延用现有蓝白/中性灰界面和公共组件；不以新效果图替代实际可用性验证。

## 5. 账号删除入口（CHANGE-023）

运营账号列表提供“删除”，详情底部也可进入。确认区明确目标备注/内部ID、仅空登记可删和不操作平台账号；点击确认按钮即可删除，无需输入名称，可取消。删除期间禁用确认/关闭/取消，失败保留确认目标及原记录，拒绝原因显示在确认区并自动滚动进入视野，后台核验刷新不得清除该提示；版本冲突必须读取最新账号并重新确认。成功关闭详情、显示删除提示并刷新列表；工作台/数据复盘重新读取的选择器不再包含该账号。服务端有关联则明确拒绝，不提供绕过或自动清理历史。


### 账号关联清理确认（CHANGE-025）

账号详情/行内删除入口先读取影响，分类展示账号专属记录和文件数量，说明共享来源/其他账号/配置保留、私有备份及无一键撤销。关联仅警告，点击“确认删除账号及关联数据”立即提交，无名称输入。预览加载及提交中禁用确认，提交中禁止关闭；版本或范围变化需刷新重新确认。失败提示在确认区域并进入视野。

提交后展示停止任务、备份、数据库清理、文件清理及真实完成/失败状态；独立“删除操作记录”保留最近20条进度，刷新/关闭后可续看。后台自动重试仍在排队/运行时不重复新建操作；终态失败提供“继续重试删除”，从同一阶段恢复。仅在文件清理完成后显示完成并刷新账号列表与选择器。通用任务页将此类失败指向运营账号的删除进度，不能取消或用通用任务重试覆盖它。

### 运行状态信息层级（CHANGE-027）

运行状态按“待处理事项→当前任务/进程→AI用量→来源”组织，详细方案见[页面重设计](../plans/CHANGE-027-运行状态页面重设计.md)。异常/待核对摘要置顶并给出操作入口，正常态不展示空告警；运行/等待/待分发数量与历史失败分开。进程技术标识、历史任务分布、用量费用及来源配额按需展开；预算/币种/未知数据和调用验证边界保留。关闭定时不当作故障，不添加自动刷新或额外后台调用。宽屏并列、窄屏单列，原生键盘展开、44px触控与局部表格横滚；监控/审计的查询状态隔离和错误重试继续保留。

### 账号新增自动时区与必须验证（CHANGE-028）

账号新增表单移除手动时区字段，使用`Intl.DateTimeFormat().resolvedOptions().timeZone`取得浏览器IANA时区随请求保存，可只读提示识别值。已有账号备注编辑保留原时区；不批量改写历史账号，也不改变工作区/来源定时计划的时区配置。

浏览器档案为新增必填，只保留“添加并验证”入口；提交中不能重复或关闭。账号登记与验证任务一次原子提交，失败不留下只创建未排队的半成品；成功显示真实排队/运行状态并继续使用既有自动结果刷新。用户明确选择“添加时必须提交验证，失败保留记录以便重试”，故提交不等待验证通过，验证失败也不移除账号；错误、冷却、换档案与重验历史继续展示。旧账号的核验状态不能自动补为成功。现有账号的备注保存和独立重验入口保留。

### 账号验证与保存交互（CHANGE-029）

当前验证结果卡优先展示结论、主页/登录身份、平台昵称与最近时间，保留后台指标未验证提示。只保留一个主验证入口；浏览器更换按需打开，用“验证所用浏览器/确认更换”解释操作。历史默认折叠，以时间线呈现时间、状态和可读原因，不堆叠绑定版本/会话ID/多组执行时间；旧成功不覆盖本次失败，更换绑定或过期仍需重验。

“确认用于运营”仅作核对后的人工声明；备注另收进“修改本地备注”，展开后“保存备注”，不替代身份确认。添加、保存备注及确认运营用途成功后关闭详情，在列表显示对应成功提示；提交失败保留原输入/详情。新增关闭后只表示登记和验证请求已提交，列表在存在在途验证时自动更新、终态停止，失败仍保留账号并可在详情重试。详见[交互方案](../plans/CHANGE-029-账号验证与保存交互优化.md)。

### 登录账号未识别的说明与指引（BUG-042）

公开主页匹配、登录身份识别与后台数据读取能力分别表达。登录unknown明确显示“未能识别当前登录账号”，解释不代表未登录；公开匹配但登录未识别时默认展示检查所选验证浏览器、在该浏览器进入自己的小红书主页核对目标、保持打开后重新验证三步指引。已登录仍识别不到时说明网页信息可能未加载完整或变化，不伪造确切原因。

auth_required提示先登录目标账号；mismatched提示先切换目标且不会自动替换登记账号；unsupported或明确不支持登录识别能力时说明当前工具限制与人工核对，不承诺反复重试能解决。匹配、在途、过期或旧绑定结果不显示这段当前登录补救指引。人工运营确认不替代登录验证或后台读取能力证明，不改变任何服务端身份/权限规则。

### 隐藏未接入的后台指标信息（CHANGE-030）

用户明确要求账号验证区不展示后台指标信息，覆盖前述保留提示的旧展示约定。移除结果卡“后台指标”状态和登录核对指引中后台数据能力说明，仅展示账号身份/登录核对；后台能力字段和身份/权限规则保持，不新增功能未接入占位提示。

### 候选列表信息分层（CHANGE-031）

按[详细规划](../plans/CHANGE-031-候选选题列表与说明层级优化规划.md)约定后续候选列表调整：单列紧凑条目，以标题、角度、状态和去重参考来源为主；共用生成限制集中按真实批次说明，评分/工时和完整关注理由进入详情，本题事实核验与未知风险在详情常显。未接入生成输入不包装成用户必填项；过期、采纳/拒绝/变体及权限规则沿用03。规则与边界见上述方案，验收证据见[逐项核对](../evidence/change031/acceptance.md)，任务事实仅维护于开发进度。

### 来源证据面板与分页归属（CHANGE-032）

“已采集线索与证据”按标题/刷新、分组筛选、紧凑卡片、分页底栏组织；桌面双列/手机单列。标题保留唯一详情入口，来源/连接健康与时间为次要信息，微博卡片不显示正文/发布时间缺失提示，小红书摘要预览与完整详情保留。分页底栏属于线索面板，显示当前筛选实际已加载条数，有更多、正在加载、失败重试和结束分别反馈；追加失败不清空前页，首次失败不冒充零结果，迟到筛选响应不覆盖新筛选。

AI来源整理为相邻独立面板，不嵌套在线索面板内；保持原已加载items/前20条整理范围和人工采纳语义。布局及边界见[设计](../plans/CHANGE-032-来源证据面板排版与分页设计.md)，任务事实以开发进度为准。

### 新增来源按类型配置（CHANGE-033）

先选类型：微博热搜榜仅名称/类型，不显示小红书浏览器、关键词或参考账号；小红书话题搜索与参考笔记均选择已连接浏览器并填写搜索关键词，只有参考笔记显示选填参考主页。浏览器短代码为连接标识；参考主页支持完整链接/24位ID，不加入运营账号列表，额外账号笔记不按关键词过滤。关键词逐一搜索，话题优先较新列表，参考笔记综合搜索并尝试部分正文。

固定标题与单一添加按钮、正文滚动，失败可见并保留输入，忙碌禁止关闭，成功关闭并在列表明确反馈尚未采集。隐藏草稿不提交，定时仍默认关闭，列表人工采集入口及原09:00/16:00北京时间规则保持。详细字段、校验与验收约定见[设计](../plans/CHANGE-033-新增来源表单按类型重设计.md)；状态只维护于开发进度。

### 删除可用工时参数（CHANGE-035）

生成候选表单仅保留栏目与来源窗口，账号由当前选择确定，不再提供本次可用工时。设置页“产能与预算”更名“AI 预算”，移除每周可用工时表单；AI金额预算与价格配置保留。生成说明不再展示历史可用工时预算，旧设置与冻结快照仅保留历史，新任务不再读取默认值。真实制作耗时/历史估时与此输入参数独立，本轮未扩展或删除相关历史数据。
