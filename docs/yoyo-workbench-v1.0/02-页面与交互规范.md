# 02 页面与交互规范

文字规则优先于效果图里自动生成的示意文案、素材数量和状态。7 张选定图见 [参考索引](references/README.md)。

## 1. 信息架构

主导航固定：工作台、选题策划、内容工作间、排期日历、数据复盘、IP 资产库。账户、通知、数据源与成员设置放在全局入口；评论/来信放内容详情的“反馈”面板，不额外增加复杂一级菜单。

建议路由是前端信息结构，不是已建地址：/workspace、/topics、/contents、/contents/{id}、/calendar、/analytics、/assets、/settings、/notifications。

## 2. 页面规格

| 页面 | 默认展示与主要操作 | 关键状态 |
|---|---|---|
| 工作台 R02 | 账号数据及时间、优先任务最多 3 项、待确认、开奖和数据缺口；点任务直达对象 | 新账号引导；数据旧标记；逾期置顶；无任务不编造建议 |
| 选题策划 R03/R04 | AI 推荐/热点榜/优质笔记三个标签；按源、主题、时效筛选；数据源设置、刷新、采纳 | 未连接源；运行中；部分失败；过期；无匹配；已采纳 |
| 内容列表 R05–R07 | 图文/视频、负责人、状态、计划时间筛选；新建或从选题进入；草稿可继续 | 空列表、新任务生成中、待素材、冲突、取消 |

| IP 资产库 R10/R11 | 素材库/成品归档，分类、搜索、收藏；批量上传、版本、引用/下载 | 上传与预览状态独立；待确认/停用；引用中不可硬删 |

## 3. 核心操作行为

### 选题采纳

候选卡显示标题、人群、来源类型/原文、来源时间/采集时间、角度、关注理由、媒体建议、成本和不确定项。没有原始引用则不能标“热点衍生”。选中查看解释，点击采纳选择图文或视频与负责人，创建唯一内容草稿并触发制作单任务。双击只创建一次；任务失败可在草稿重试，不重新建内容。

“立即刷新”展示各来源独立状态，不禁用整个页面。采集进行中再次点击进入现有任务；不能无限并发。推荐结果保留批次，刷新不删除已经采纳或人工修改的候选。

### 编辑与内部审核

保存形成可恢复草稿快照。提交前展示必须补齐项；提交后锁定待审版本，允许退回编辑但必须撤销该审核请求。审核者可通过或退回并记录意见。本人兼任审核允许，但操作留痕。确认后修改任何发布载荷必须生成新版本并重新审核；排期时间的纯调整不修改发布载荷。

图文页次通过拖动调整，键盘按钮亦可操作。视频镜头使用序号与起止秒数，时长冲突给出定位。更换图文/视频类型弹窗说明需要新建转换版本，原稿保留。

### 发布归档

待发布内容可导出固定版本发布包。点击“登记已发布”打开表单：笔记链接/ID、实际发布时间、确认版本、活动属性、投放属性。确认后产生发布记录；提供“我稍后补链接”时只进入发布待核对记录，不进入正式效果统计，待补 ID 后完成。此暂存记录不是已验证发布。

### 开奖详情

显示活动名、原帖、规则版本、参与截止、开奖时间、负责人、提前提醒与状态。待开奖可“标记已开奖”，必须填写实际时间与结果记录；已开奖可“记录公布结果”，需链接或说明附件。已读/稍后提醒不算完成。暂停或取消需填写原因；修改已公开时间提示同步原帖，不自动发帖。

### 数据导入

选择账号和数据类型 → 上传截图/表格 → 异步识别 → 原始材料与提取表并排 → 修正匹配笔记、窗口、指标和单位 → 确认批次。低置信、缺时间、未匹配 ID、重复冲突突出显示；允许先排除问题行，再确认有效行。未确认行永远不影响正式看板。

### 资产选择

从制作单打开选择器时展示可复用资产优先。选中记录具体版本与用途，视频可选片段范围。待确认资产可加入草稿，但显示阻塞原因；正式内部通过前须解决。预览不支持时可查看人工上传预览/下载文件，不打开不可控的原文件代码。

## 4. 表单约束

| 表单 | 必填 | 规则 |
|---|---|---|
| 账号 | 名称、平台、平台 ID、时区 | 只存公开链接，不要求用户在表单粘贴平台密码 |
| 内容 | 标题、类型、负责人、制作单版本 | UI 示例字数不是平台硬限制；实际发布约束配置化 |
| 图文提交 | 发布图片、顺序、标题正文、素材引用处理 | 已上传成功且文件可用；图片数量限制来自经验证的平台配置 |
| 视频提交 | 成片、封面、标题正文、字幕/声音检查 | 分镜并非强制有配音；无配音可标不适用并说明 |
| 活动启用 | 原帖关联、规则、截止、开奖、负责人、提醒 | 发布≤截止≤开奖；实际发布后重验；时区可见 |
| 资产 | 名称、类型、源文件、归属、状态 | 使用范围未确认不能标已确认；文件大小限制前端后端一致 |
| 数据确认 | 目标、指标、值/缺失、口径、窗口或快照时间、来源 | 数量不可负；净增可以负；比例明确单位与分母 |

## 5. 通用异常与可用性

加载用稳定骨架，不显示虚假零；空态提供唯一明确下一步；403 显示无权限；404/归档对象说明原因；409 显示另一人修改时间并可比较，不覆盖；429 显示稍后重试；异步失败保留输入；离线不宣称保存成功。

通知入口展示未读数与任务链接。已取消/变更事件的旧通知显示“已失效”，不再引导执行。旧素材被停用时，从内容进入可查看原因与替代方案。

主要桌面宽度按 1440 设计，1280 仍可完整操作；更窄时抽屉/表格滚动而非缩小到不可读。移动端首版仅保障查看待办、通知、内容概览与状态确认，重型上传/制作表单优先桌面。键盘可操作，焦点明确，状态不只靠颜色，正文对比度与可读性上线前实测。

UI 默认 8px 间距体系、中文无衬线、蓝白与中性灰，禁止用角色肤色等装饰色承担不可读正文。品牌主色不代表所有按钮文字均可直接使用白字，设计实现需校验对比度。官网 logo/字体/角色资产使用真实原文件，不从效果图裁取。
