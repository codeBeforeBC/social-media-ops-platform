# 07 AI 工作流与评估

v1.2｜2026-10-09。取消图文/视频制作单、素材标签、内部辅助检查及全部AI排期；保留来源整理、选题、周报和反馈。AI执行边界由服务端控制，不需要新Agent架构。

## 1. 输入输出

输入account_id、任务目标、输入版本、冻结来源证据、已激活运营策略、实际指标（可空）、人确认产能与语言。不查询品牌规范库/素材库，不传rule_set_id、required_asset_ids或asset_version_ids；历史素材快照不能继续进入新任务。

输出schema_version/input_version/summary/evidence_refs/assumptions/missing_inputs/warnings/task_payload。严格结构、输入ID白名单、最多一次修复；失败明确留输入及用量。时间/数字/事实由服务端复验，外部文本指令视为数据。

## 2. 保留工作流

| 工作流 | 必须输出 | 约束 |
|---|---|---|
| 来源整理 | 主题、人群需求、原文摘要、去重建议 | 不编造已读原文/榜单/增长 |
| 选题推荐 | 最多6候选：标题、人群、场景、关注理由、原创角度、证据、形式、估时与评分 | 不输出逐页/分镜/成品文案；形式是推荐，采纳只留决策 |
| 周报 | 程序计算的facts、hypotheses、actions、missing_data | 不补数或保证因果；事实引用calculation_id及观察集合 |
| 反馈整理 | 分类、回复草案、许可内选题线索 | 不自动发送，不伪造投稿，撤回资料不可继续引用 |

TopicCandidate保留title/audience/need/scene/column/emotion/media_type/follow_reason/evidence_refs/original_angle/score_breakdown/estimated_hours?/expires_at?/assumptions；删除required_asset_ids。所需资源可作为普通文字的不确定项，不可链接或重新创建资产管理。角色表达是选题质量维度，基于任务背景与运营策略，不构建品牌文件/规则激活。

## 3. 评分与事实

延用六项0–5分：受众需求25%、YOYO表达25%、连续关注理由20%、内容清楚15%、可执行性10%、时机5%；服务端计算总分，不称爆款概率。缺来源按常青提案标注，缺真实工时保留null；缺资产/规范不再是任务错误或固定missing_inputs。

fact仅引用冻结来源中的非空原文片段；原文存在不等于内容已核实。解释用inference或original_hypothesis，任务字段不能假装外部证明。周报策略先proposed，人确认才active，保留证据和复查日期。

## 4. 运行与成本

保留现有网关的权限/输入版本守卫、结构/引用校验、修复、缓存、超时、取消、用量和预算。每次记录模型/提示词/Schema/输入版本；删除资产/规范缓存键和过期查询，换版本后不复用旧输出。历史缓存/旧幂等结果分版本隔离。

沿用已确认DeepSeek服务及本地使用者的数据/预算授权；不限预算模式仍计真实token，未知单价记unknown，不记0或冒充账单。其他部署按自己的配置启用，不随clone分发凭据。来源/AI失败保留已有题和笔记登记和手工导入能力。

## 5. 新范围评估

不少于20例：无来源、过期/矛盾来源、常青题、零素材/规范库、恶意外文指令、未知工时、重复采纳、缺归因、混合流量、小样本、伪造ID/数字、反馈许可撤回和旧结果版本。原图文/视频制作单及排期用例保留历史，不计本版适用覆盖。

硬门槛：结构合法或明确失败、事实/数值/ID不伪造、不执行生产或排期/活动工作流、权限不越界、人工决策不自动覆盖、缺失指标不推算。质量延用逐例五项（角色表达、可执行性、原创角度、中文自然度、关注理由）各≥3且总分≥20，输出哈希绑定评审；自动技术评审不冒充使用者业务认可。

模板/Schema变更后S3-07重新验收，并覆盖真实提供方新输入/输出样本；不得沿用旧20例通过结论宣布新工作流通过。报告/反馈尚未实现的评估在相应S8任务完成后留证，模拟指标不得充当产品复盘实测。
