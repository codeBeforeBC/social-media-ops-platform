# 12 · 测试与验收

v1.0｜2026-10-06。本文件是未来实现的验收计划，**不是已经测试通过的报告**。每项结果必须附环境、构建版本、执行人、时间、输入和截图/日志。

## 指标金标准算例

| 输入 | 应输出 |
|---|---|
| 同口径期初 600、期末 631 粉丝 | 净增 31；不能称新增关注 31 |
| 只有粉丝快照 631 | 净增为空，原因“缺期初值” |
| 同窗口笔记归因关注 12、阅读 3000 | 千次阅读关注 4 |
| 归因关注 12、阅读 0 或缺失 | 比率为空，分别说明零分母/数据缺失 |
| 累计点赞快照 100 → 150 | 若边界一致，区间增量 50；不求和为 250 |
| 同逻辑键重复导入阅读 3000 | 有效观察仍为一条，统计仍 3000 |
| 组合字段“获赞与收藏 1579” | 保存组合观察；点赞/收藏独立字段仍为空 |
| 两视频平均观看 10 秒、20 秒，各对应观看次数 100、300，且口径一致 | 加权平均 17.5 秒；无权重时不得算总体均值 |
| 后台值“1.2 万” | 12000，approximate=true；界面保留约数提示 |
| 相同日期不同流量口径 | 分开统计；不能直接拿自然流量与混合流量做增长结论 |

补充累计值回落测试：100 → 90 不能当作新增 −10 而不解释，应标记平台修正/删帖等待核实；真实累计变化可保留，派生增长报告提示异常。

## AI 评估与端到端演练

按 07 的离线集测试引用、事实、IP 一致性、可制作性和字段完整性。硬错误（伪造数字、引用不存在、外部指令越权）不能用平均分抵消。

演练 A：真实采集 → 选题 → 图文制作单 → 上传设计稿 → 内部审核 → 计划发布 → 人工真实发布或沙盒发布回填 → 截图确认 → 复盘。演练 B 使用视频并关联已有 3D 素材。演练 C 使用测试抽奖活动压缩时间验证到点、改期、重启、开奖和公告。沙盒结果不得伪装为平台生产接入证据。

## 发布准入与缺陷级别

阻断级：数据泄漏/丢失、伪造数据、错误账号发布记录、静默漏提醒、无法完成主流程。重要级：单一核心功能不可用或口径错误。一般级：有明确替代路径的非核心体验问题。

首版准入：R01–R15 覆盖、阻断和重要问题清零、三类自动来源验证、恢复演练、真实媒体样本、AI 硬门槛全部完成。来源未打通时只能声明“内部试用版 / 部分能力可用”，不能宣布完整首版完成。商业涨粉效果需要上线后观察，不作为可保证的软件通过标准。
