## 指标金标准算例

| 输入 | 应输出 |
|---|---|
| 同口径期初 600、期末 631 粉丝 | 净增 31；不能称新增关注 31 |
| 只有粉丝快照 631 | 净增为空，原因“缺期初值” |
| 同窗口笔记归因关注 12、阅读 3000 | 千次阅读关注 4 |
| 归因关注 12、阅读 0 或缺失 | 比率为空，分别说明零分母/数据缺失 |
| 累计点赞快照 100 → 150 | 若边界一致，区间增量 50；不求和为 250 |
| 同逻辑键重复导入阅读 3000 | 有效观察仍为一条，统计仍 3000 |
| 组合字段“获赞与收藏 1579” | 保存组合观察；点赞/收藏独立字段仍为空 |
| 两视频平均观看 10 秒、20 秒，各对应观看次数 100、300，且口径一致 | 加权平均 17.5 秒；无权重时不得算总体均值 |
| 后台值“1.2 万” | 12000，approximate=true；界面保留约数提示 |
| 相同日期不同流量口径 | 分开统计；不能直接拿自然流量与混合流量做增长结论 |

补充累计值回落测试：100 → 90 不能当作新增 −10 而不解释，应标记平台修正/删帖等待核实；真实累计变化可保留，派生增长报告提示异常。

## 评估与纵向演练

AI按07新范围固定集验证，结构/事实/ID/权限硬错误不能用均分抵消。取消原图文/视频制作演练，保留外部图文/视频分析维度。

演练A：真实来源 → 新选题 → 采纳决策 → 独立已发布笔记登记 → 真实后台截图/表格确认 → 指标/复盘。外部制作/发布不作为本系统操作；使用沙盒登记时显式隔离，不能冒充真实平台发帖。

演练B：独立笔记 → 重复/部分确认数据 → 冲突更正 → 撤销早期批次且保留后续有效结果 → 旧报告stale → 重算/策略人工采纳；反馈许可与撤回验证，不自动发送。

演练C：从现有旧库副本升级及从空库安装 → 旧制作/资产及排期/活动/回收任务不再执行，来源定时采集仍运行 → 笔记/选题/来源/导入基础保留 → 备份恢复和兼容应用回滚。物理表/文件清理单独核对引用与备份。
