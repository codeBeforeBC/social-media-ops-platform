# 03 业务状态与权限

v1.4｜2026-10-25｜业务枚举唯一基线。[CHANGE-008](../decisions/ADR-008-删除排期日历与活动.md)取消内容/资产及日历/活动/提醒状态机。实际使用者仍承担本地实例全部业务责任，权限由服务端验证。

## 1. 成员与兼容

2026-10-25 CHANGE-014覆盖个人登录/成员协作需求：每位使用者独立运行本地实例，工作台不再区分自然人用户。自动使用一个稳定的内部默认用户和默认工作区；无邮箱密码设置、登录/退出、邀请、成员停用/移交或角色选择。详细目标与兼容规则见[CHANGE-014免登录规划](../plans/CHANGE-014-本地单实例免登录规划.md)；实现状态仅见台账。

默认用户仅用于业务归属、任务和审计，不是公共登录账号或默认密码。新写入由服务端填默认身份，默认工作区不能由客户端身份参数切换；运营账号仍为真实平台账号，其连接/授权不随内部登录退出而取消。

已有单工作区、单有效成员实例沿用原user/member/workspace ID。历史用户、创建人、负责人、通知收件人和审计保留，不批量改写；多工作区/多有效成员且无默认映射的旧库先明确选择，不静默合并。新任务归属默认身份；旧任务保留原发起者并验证原资源/输入条件，不再依赖浏览器登录session。

通知统一为本实例的通知中心；审计保留业务操作追溯，不声称区分自然人。内部admin标识可作为既有业务接口的兼容实现，不再作为产品角色。CHANGE-012的个人登录/全员管理员与旧角色矩阵仅保留历史记录，不继续约束本版目标。

保留本机回环发布、Host/Origin/CSRF、工作区/账号/文件用途、签名和解析隔离；技术请求令牌不代表用户登录。保留旧内部密钥及已加密邀请幂等记录；不因删除登录而清空历史身份表或业务外键。

## 2. 选题及实际笔记

选题 proposed/accepted/rejected/expired；过期为展示/守卫规则，已采纳题保留决策与来源并提示重新核验。同一题默认一次采纳，重复请求复用 TopicDecision；显式变体另建题并关联父题。采纳不产生 Content、修订、Job或实际发布。

Publication.lifecycle：active/deleted；只有经人工确认身份/账号/实际时间的笔记才可登记。没有 draft/in_review/ready_to_publish，不保存发布载荷、批准哈希或成品。平台ID在账号内唯一；外部删除保留记录与指标，重发新ID另建；登记更正使用 expected_version、原因及审计，身份不能随普通编辑挪用历史指标。

复盘进度 awaiting_data/ready/drafted/reviewed 根据数据完整性与报告派生，不修改笔记的 active/deleted；没有排期到期状态或回收提醒。

## 3. 导入与文件

ImportBatch：uploaded/parsing/needs_confirmation/committing/confirmed/partially_confirmed/failed/reverted。ImportRow：valid/conflict/unmatched/excluded/confirmed。仅确认本次选择且合法的行；未确认数据不进正式看板。撤销保留来源、更正链及报告stale标记。

UploadSession：created/uploading/completed/expired/aborted/failed。FileObject.file_status：uploading/ready/failed/quarantined；preview_status：not_requested/processing/ready/unsupported/failed，仅用于导入/证据处理。文件成功不等于数据已确认；权限同时校验工作区、账号和引用目的。

## 4. 日历与活动状态退出

R08/R09全部取消；不再定义或创建Campaign、CalendarEvent、ReminderRule、ReminderOccurrence及排期建议。旧状态只供受限历史迁移核对，不能由通用待办恢复业务操作。详细取消边界见11。

## 5. 通知、任务及一致性

Notification：unread/read/superseded；送达pending/sent/failed。通知中心已读不代表来源、导入或复盘任务已完成。取消功能的旧通知保留审计并失效，移除操作链接。

Job/CollectionRun：queued/running/succeeded/partial/failed/cancelled。SourceConnection.health：unverified/healthy/degraded/auth_required/rate_limited/unavailable/disabled。Feedback.status：new/triaged/archived；许可unknown/internal_only/approved/revoked。Report.status：draft/partial/final/stale；StrategyMemory：proposed/active/retired；MetricObservation.validity：confirmed/superseded/reverted。

笔记登记、数据确认和策略采纳与审计同事务；需要异步处理时Outbox同事务，但笔记登记不创建回收/提醒事件。新业务自动归属默认身份，不再提供成员移交；历史归属及旧任务兼容规则按CHANGE-014保留。AI无发帖、排期/活动、指标确认或权限变更能力。

2026-10-25 CHANGE-013：SourceConnection.enabled仅控制定时自动采集。关闭定时仍允许人工立即采集与验证，暂停来源仅允许验证恢复，手动/验证/定时共用同源单并发及最小间隔。开关和时间窗口变化不使人工采集/验证输入过期；实际来源配置、负责人、暂停或配额变化继续阻止旧结果提交。关闭定时不改变真实健康状态，也不主动恢复暂停。

## 6. 旧状态退出

Content/ContentRevision/Review、Asset/AssetVersion/AssetUsage、BrandRuleSet、发布包及日历/活动/提醒状态仅属旧数据，不参与当前业务或验收。旧排队/运行制作单、预览、导出及日历/活动/回收提醒任务须在切换时停止并标明取消原因；提交结果时再检查范围版本，避免删模块后旧worker继续落库。历史执行记录与用量不抹去。迁移顺序见ADR-007/008，不能通过枚举替换直接改写旧记录。

## 7. 小红书账号核验与人工管理确认（CHANGE-020）

运营账号只支持小红书新增。登记存在不等于平台身份/登录有效；旧账号无证据时保持未验证。目标公开身份matched/inconclusive/not_found、登录身份unknown/matched/mismatched/auth_required/unsupported、各项读取能力unknown/supported/unsupported独立保存；任务继续使用既有Job状态。公开身份匹配且登录不一致为partial，保留错号提示，不授予后台读取能力。

每次核验冻结目标内部ID、浏览器档案context ID及identity_binding_version；结果一次落库后不可修改，取消/绑定变化/租约失效不应用迟到结果。档案变化增加独立绑定版本，清除当前确认；备注/时区编辑保留身份观察。60秒同账号/绑定冷却，同绑定活动任务复用；失败重验创建新记录，不复写原任务。

确认管理此账号需要显式声明、当前绑定的最新公开身份匹配结果和24小时内观察证据，并校验expected_version；它只记录人工管理声明，不证明平台所有权/授权。过期或换绑定后需重验；无数据的未验证状态不阻止原手工导入、历史指标或选题。后台指标未实际读取时必须为unknown。

## 8. 空运营账号删除（CHANGE-023）

允许管理员在点击显式确认按钮并校验expected_version后删除空账号登记。账号只要有业务、文件、导入、验证、任务、事件或保留的历史表外键关联，就拒绝删除并给出类别；在途任务/待处理事件单独提示。不能通过取消任务或验证失败绕过历史保护，不连带删除数据。无效旧平台ID不妨碍删除真正的空登记。

删除事务锁定父账号后检查全部外键，防止检查后并发新增关联；仅删除account_memberships和账号本身，保留追加式审计及幂等记录。相同删除键重复返回原结果；旧创建/编辑键不能复活已删除账号，同一平台身份重新登记时使用新UUID。操作只针对本地登记，不删除或退出真实平台账号。本范围不包含已有历史账号的归档或删除历史。


## 9. 账号及专属数据强制删除（CHANGE-025）

此规则覆盖第8节的页面删除限制。管理员先查看影响分类，再点击“确认删除账号及关联数据”，不输入名称。一般专属关联只作警告；共享来源、默认用户/工作区、配置、浏览器档案/平台会话和其他账号保留，不操作平台上的账号或笔记。兼容旧客户端的非force请求仍只允许删除空登记。

确认须携带expected_version及影响指纹；账号或关联范围变化后重新核对。接受后账号进入删除状态、退出日常账号列表，拒绝继续业务写入及敏感资源读取。独立删除操作以stopping → backing_up → purging → cleaning_files → completed执行，失败保留phase和清单；旧任务取消并撤销租约，等待实际执行/清理退出或明确执行期限，数据库写屏障阻止迟到结果。普通业务的历史不可变约束保留，只有删除操作事务中的已确认记录可清理。

先保存私有账号快照/文件备份，再事务清理专属业务、任务、事件、验证及retired历史；随后中止分片、清理原件/预览及崩溃预览残留。账号已移除但文件未清完时不得报告全部完成；独立操作不依赖原账号，关闭页面/重启后仍可查询和重试。已发生AI用量与费用留脱敏台账参与预算，旧幂等响应去除正文并保留删除墓碑，禁止旧请求重新登记。删除操作最小审计及备份独立保留，页面不提供一键撤销。未知跨账号引用或备份/存储故障明确失败，不扩大删除边界。
