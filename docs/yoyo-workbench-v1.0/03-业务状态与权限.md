# 03 业务状态与权限

v1.2｜2026-10-09｜业务枚举唯一基线。[CHANGE-008](../decisions/ADR-008-删除排期日历与活动.md)取消内容/资产及日历/活动/提醒状态机。实际使用者仍承担本地实例全部业务责任，权限由服务端验证。

## 1. 成员与兼容

| 能力 | 管理员 | 编辑 | 运营 | 只读 |
|---|---|---|---|---|
| 查看授权工作区/账号数据 | 是 | 是 | 是 | 是 |
| 成员、来源密钥引用、运行设置 | 是 | 否 | 否 | 否 |
| 采纳/驳回选题 | 是 | 本人事项 | 是 | 否 |
| 登记和更正已发布笔记 | 是 | 否 | 是 | 否 |
| 导入确认、复盘策略采纳、反馈维护 | 是 | 否 | 是 | 否 |
| 查看导入原图/表格 | 是 | 按账号权限 | 是 | 按账号权限预览 |
| 下载私有导入原件 | 是 | 否 | 是 | 否 |

目标角色：admin/editor/operator/viewer，允许组合。旧 reviewer 停止提供新角色选项；迁移已有成员时仅保留授权账号的读取能力，不自动提升运营或管理权限，组合角色其他权限保留并记录转换。不因删除角色而删除成员/历史操作者。asset.edit/content.production/content.copy/review及日历/活动/开奖专属权限退出，按保留动作收口为选题、导入和运营权限。

## 2. 选题及实际笔记

选题 proposed/accepted/rejected/expired；过期为展示/守卫规则，已采纳题保留决策与来源并提示重新核验。同一题默认一次采纳，重复请求复用 TopicDecision；显式变体另建题并关联父题。采纳不产生 Content、修订、Job或实际发布。

Publication.lifecycle：active/deleted；只有经人工确认身份/账号/实际时间的笔记才可登记。没有 draft/in_review/ready_to_publish，不保存发布载荷、批准哈希或成品。平台ID在账号内唯一；外部删除保留记录与指标，重发新ID另建；登记更正使用 expected_version、原因及审计，身份不能随普通编辑挪用历史指标。

复盘进度 awaiting_data/ready/drafted/reviewed 根据数据完整性与报告派生，不修改笔记的 active/deleted；没有排期到期状态或回收提醒。

## 3. 导入与文件

ImportBatch：uploaded/parsing/needs_confirmation/committing/confirmed/partially_confirmed/failed/reverted。ImportRow：valid/conflict/unmatched/excluded/confirmed。仅确认本次选择且合法的行；未确认数据不进正式看板。撤销保留来源、更正链及报告stale标记。

UploadSession：created/uploading/completed/expired/aborted/failed。FileObject.file_status：uploading/ready/failed/quarantined；preview_status：not_requested/processing/ready/unsupported/failed，仅用于导入/证据处理。文件成功不等于数据已确认；权限同时校验工作区、账号和引用目的。

## 4. 日历与活动状态退出

R08/R09全部取消；不再定义或创建Campaign、CalendarEvent、ReminderRule、ReminderOccurrence及排期建议。旧状态只供受限历史迁移核对，不能由通用待办恢复业务操作。详细取消边界见11。

## 5. 通知、任务及一致性

Notification：unread/read/superseded；送达pending/sent/failed。个人已读不代表来源、导入或复盘任务已完成。取消功能的旧通知保留审计并失效，移除操作链接。

Job/CollectionRun：queued/running/succeeded/partial/failed/cancelled。SourceConnection.health：unverified/healthy/degraded/auth_required/rate_limited/unavailable/disabled。Feedback.status：new/triaged/archived；许可unknown/internal_only/approved/revoked。Report.status：draft/partial/final/stale；StrategyMemory：proposed/active/retired；MetricObservation.validity：confirmed/superseded/reverted。

笔记登记、数据确认和策略采纳与审计同事务；需要异步处理时Outbox同事务，但笔记登记不创建回收/提醒事件。移除负责人先移交或转管理员并产生待办。AI无发帖、排期/活动、指标确认或权限变更能力。

## 6. 旧状态退出

Content/ContentRevision/Review、Asset/AssetVersion/AssetUsage、BrandRuleSet、发布包及日历/活动/提醒状态仅属旧数据，不参与当前业务或验收。旧排队/运行制作单、预览、导出及日历/活动/回收提醒任务须在切换时停止并标明取消原因；提交结果时再检查范围版本，避免删模块后旧worker继续落库。历史执行记录与用量不抹去。迁移顺序见ADR-007/008，不能通过枚举替换直接改写旧记录。
