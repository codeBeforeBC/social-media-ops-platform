## 后续记录模板

复制下面模板追加为新的日期条目；LOG 编号连续递增，实际未执行的内容不能写成成功。

```markdown
## YYYY-MM-DD · LOG-005 · 本轮事项
- 关联任务：Sx-xx / BUG-xxx。
- 状态变化：TODO → DOING / VERIFY / BLOCKED / DONE。
- 已完成：具体改动与文件。
- 未完成：剩余步骤。
- 验证：环境、构建、命令/人工步骤、结果、证据路径；未运行项及原因。
- 阻塞/决策：输入或变更编号、解除条件。
- 工作位置：目录、分支/提交（无则写无）、持续运行服务（无则写无）。
- 下一步：下一次可以直接开始的动作。
```
