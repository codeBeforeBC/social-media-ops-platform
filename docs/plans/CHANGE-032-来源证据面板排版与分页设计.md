# CHANGE-032 来源证据面板排版与分页设计

2026-10-30；依据用户对“已采集线索与证据”排版及加载更多按钮夹在两个区域之间的批注。状态仅维护于[开发进度](../tracking/开发进度.md)。

面板依次组织为标题/刷新、分组筛选、紧凑线索卡片、独立分页底栏。桌面双列、手机单列；标题是主要阅读和键盘详情入口，类型/时效为次要标签，来源名称/连接健康和采集/发布时间使用较小文本。标题不继承全局按钮的大间距，小红书摘要只预览两行、详情保留全文；微博卡片不恢复正文或发布时间占位。采集时间显示到分钟，完整秒数保留在时间提示和详情。

筛选区使用统一背景、边框和44px输入/操作；关键词占主要宽度，窄屏换行。分页底栏属于线索面板，独立背景/边框、留足上下间距，显示当前筛选已加载的实际条数及加载更多按钮；未知总数不编造。手机按钮整行，结束后明确当前筛选已加载完。分页读取失败在底栏原位提示并可重试，保留已有线索；首次读取失败不冒充空结果，筛选迟到响应不覆盖新结果。

“AI 来源整理”从嵌套面板移到相邻独立面板，保持同一份已加载items及原前20条整理输入规则，区域间至少20px可见间距。此轮不增加采集、模型调用或自动整理，也不修改来源/事实/观察记录和权限语义。

验证范围：有更多/加载中/追加失败重试/完成、追加去重、首次失败/快速筛选竞态、标题键盘详情/Esc焦点返回、微博/小红书差异及原整理流程；1440/1280/768/390/320布局。本轮[实际验收证据](../evidence/change032/README.md)与示例截图分开，不把合成来源当真实采集。
