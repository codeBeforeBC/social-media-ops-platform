# CHANGE-033 新增来源表单按类型重设计

2026-10-30；约定仅描述设计与边界，实施事实以[开发进度](../tracking/开发进度.md)为准。

先选择“采什么”，再填写对应配置。抽屉固定标题与添加按钮，中间独立滚动，底部只保留一个提交入口；说明直接贴近字段，不把底层字段名作为用户任务。

| 来源类型 | 展示内容 | 真实采集含义 |
|---|---|---|
| 微博热搜榜 | 类型、来源名称 | 匿名读取公开热榜标题/热度；无需关键词或小红书浏览器 |
| 小红书话题搜索 | 类型、名称、采集使用的浏览器、搜索关键词 | 对每个关键词搜索较新的笔记列表，作为话题线索 |
| 小红书参考笔记 | 上述字段及选填参考账号主页 | 综合搜索并尝试读取部分正文；另外读取最多2个账号的公开笔记，这部分不按关键词过滤 |

浏览器从现有连接列表选择，不要求用户手填档案ID。说明短代码是浏览器连接标识，既不是小红书账号ID，也不保证已登录；用户应先登录小红书并启用浏览器连接插件。无连接时提示打开浏览器/连接插件/刷新列表，读取失败原位显示并可刷新。不新增登录认证或自动打开平台动作。

搜索词空白默认，示例仅作占位，不静默替用户选择方向。支持中英文逗号、顿号、换行，去空白与完全重复值；必填、最多10个、每个100字符。话题与参考笔记分别解释搜索排序/正文能力，不承诺全部内容或无限条数，实际以运行记录为准。

参考账号输入完整官方个人主页，每行一个、最多2个，也兼容24位内部ID。复用账号身份解析器，本地提取规范ID，丢弃链接查询参数，不提交跟踪参数；拒绝昵称、展示号、笔记链接和重复账号。明确这是额外公共参考来源，不会加入运营账号列表或声明账号所有权。

切换来源保留草稿方便返回修改，但提交只构造当前类型的有效配置：微博config为空；话题只有浏览器和关键词；参考笔记额外带非空参考ID列表。平台/provider由类型决定。创建仍只保存来源配置、默认关闭定时，不触发采集。说明列表“立即采集”入口和启用定时后的原北京时间09:00/16:00规则，不改来源调度时区。

提交中禁用修改、关闭和重复点击。输入错误或API失败在标题下可见，保留草稿供修正/重试；成功关闭抽屉，列表反馈“来源已添加，尚未采集”，刷新列表。沿用既有来源健康/运行记录/配额/暂停及业务守卫，无新API、契约、迁移或依赖。

验收覆盖三种字段分支、隐藏值不提交、主页规范化/重复/超限、关键词校验、连接失败与刷新、保存失败与重试、提交忙碌、成功关闭、Esc焦点返回，1440/1280/768/390/320宽度标题/底部可见且无横溢出。隔离数据库验证写入，实际本地仅只读预览，不能把表单保存当采集或登录验证通过。
