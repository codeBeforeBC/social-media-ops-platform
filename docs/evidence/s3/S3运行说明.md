# S3运行说明

使用根目录README的Compose或原生入口。每个clone的本地使用者负责自己的配置、登录、材料和人工采用。仓库不包含密钥或浏览器登录态。

## AI

原生使用受限配置文件经stdin导入：`pnpm ai:config set < /受限目录/config.json`；`pnpm ai:config status`仅显示非敏感状态；`pnpm ai:config enable` / `disable`控制新调用。默认路径Git忽略且0600。

Compose使用同一持久state卷：`docker compose exec -T worker node dist/tools/ai-config.js set < /受限目录/config.json`，随后以同一命令入口执行status/enable/disable。不要把密钥放argv、前端或提交到Git。

以下模板的不限预算与任意数据发送仅适用于已经自行授权的使用者；本项目当前使用者已授权。未授权时保持disabled；限额模式须填确认的pricing、per_task和daily，缺单价不能假定费用为零。

```json
{
  "provider": "deepseek",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "api_key": "REPLACE_WITH_YOUR_OWN_KEY",
  "enabled": false,
  "allowed_data_types": "any_user_authorized",
  "budget": {"mode": "unlimited_user_authorized", "per_task": null, "daily": null},
  "authorization_date": "填写自己的授权日期",
  "timeout_seconds": 90,
  "max_output_tokens": 16000
}
```

默认45秒/8192输出上限；本轮真实验收使用90秒/16000。失败和截断可查任务/调用账本，实际token与费用分开记录；最多一次结构修复。输入版本或人工锁定变更后重新生成，候选比较后由使用者点击应用，过期版本409拒绝覆盖。

## 浏览器来源

微博匿名热榜无需浏览器登录。小红书依赖宿主Node24/npm、Chrome及OpenCLI Browser Bridge扩展和使用者登录；运行 `pnpm sources:setup`安装固定1.8.8及校验补丁，再 `pnpm sources:bridge`启动本机59025服务。使用固定CLI的doctor检查daemon、扩展和profile：`node .local/providers/opencli/node_modules/@jackwener/opencli/dist/src/main.js doctor`。该链路不能仅靠Docker自动取得登录态。

Compose在受限且Git忽略的.env配置 `SOURCE_BRIDGE_URL=http://host.docker.internal:59025` 和宿主 `.local/state/source-bridge-token` 中的token；不要分享.env或把token写证据。原生可直接调用固定宿主适配器。来源连接创建后先验证，再启用定时；默认09:00/16:00，电脑休眠或服务停止时无法在线采集。

设置→来源连接：默认关键词旅行、IP、潮玩、情绪价值。综合参考笔记可配置0–2个真实公开参考账号的24位ID；最新搜索信号与参考账号列表分别显示，不标成官方榜。实际关键词覆盖和详情失败进入运行记录；未知平台剩余配额保存null，不编数字。认证/访问/限流失败暂停并通知，使用者恢复真实登录后验证连接再恢复运行。

公开互动只用于参考，不等于后台阅读、自然涨粉或活动有效期。来源捕获时间和活动日期分别保存，未知日期保持未知；不下载账号媒体或评论。素材所有来源/有效历史版本可引用，保留溯源；当前PNG素材/PDF规范范围不因此自动扩大。

## 开发验证

`pnpm check:s2`准备专用存储/解析器并执行基础回归。AI评估使用 `pnpm ai:evaluate`，显式配置输出路径保留各轮报告；会真实调用提供方。测试及探测只使用 `_test` 数据库并可清空，使用同一测试库的命令须串行，不能与运行中的评估并发重置。

本阶段仅生成制作单与草稿，不生成实际图像/视频成片，也不自动审核或发布。阶段证据见 [验收](S3阶段验收.md)。
