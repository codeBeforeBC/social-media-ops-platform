## 第2阶段真实能力证据

[最小探测源码](../../../tools/s0/probe-xhs-account-identity.mjs)固定OpenCLI 1.8.8，在已有授权浏览器档案执行有界只读观察，复用项目既有导航兼容方式；只提取身份白名单字段，不读取Cookie、token、原始完整用户状态或后台指标。[受控判定测试](../../../tests/xhs-account-probe.test.mjs)覆盖错号、缺字段、不同证据冲突、登录墙、安全控件及脱敏。

agent-reach CLI不在当前PATH，doctor无法执行；按已读路由及项目固定依赖复用本地OpenCLI，实际profile list确认现有档案连接。没有安装/升级后端或更换用户会话。当前配置没有明确来源档案引用，因此本探测选择实际发现且已授权的连接档案，并在报告中限定为该观察会话，不把它写成已登记账号绑定。

[真实脱敏探测](identity-probe.json)、[能力与限制](capability-report.json)、[运行摘要](probe-runtime.log)表明：

| 检查项 | 实际观察 | 限制 |
|---|---|---|
| 当前登录稳定身份 | “我”的主页链接与用户状态里的稳定ID一致，跨页面保持一致 | 观察时点有效，不构成永久登录或平台授权 |
| 公开主页身份 | 实际主页路径与观察目标ID一致，昵称及小红书号存在 | 身份来源为渲染后的官方路径和资料，不冒充独立身份API返回 |
| 昵称/展示号 | 从公开主页实际DOM读取 | 展示号不能代替内部ID，昵称不可证明控制权 |
| 后台指标 | 未读取、能力unknown | 不声称支持自动后台同步、指标入账或授权 |
| 登录失效/风控 | 受控测试中停止并保留未知 | 未在真实账号强制退出或故意制造限流 |

**当前已登记账号并未因此被验证。** [登记身份核对](registered-identity-check.json)表明，已存内部ID不符合24位内部ID格式，且与本次当前会话的身份不同。探测以当前授权会话账号为能力样本；没有自动更换已登记账号、转移历史数据或写入“已验证”状态。后续应人工核对目标身份，不能把这项能力试验当成原账号认证成功。

完整原始身份输出仅在受限 `.local/change020/identity-probe.json`、0600；Git报告仅保留必要字段存在性、时间、比对结果和SHA256。复现命令（真实参数仅在本机使用）：

```sh
node tools/s0/probe-xhs-account-identity.mjs \
  --profile <当前已授权档案> \
  --output .local/change020/identity-probe.json \
  --report docs/evidence/change020/identity-probe.json
```

省略target-id时明确以当前会话账号为能力样本；只有已经人工确认的24位目标ID才能通过 `--target-id` 指定另一个探测目标。脚本不实现产品验证接口、任务队列或管理确认；这些不属于本页首轮P01/P02范围，后续交付见full/README.md。
