# ADR-009 仅支持 arm64 容器交付

日期：2026-10-13（Asia/Shanghai）。用户明确取消 amd64 环境的容器支持。变更编号：CHANGE-009，覆盖 [ADR-003](ADR-003-本地一键启动与交付方式.md) 的多架构交付要求。实际实施与验收状态只维护在[开发进度](../tracking/开发进度.md)。

## 当前交付范围

容器交付、预构建镜像、离线包和运行验收仅支持 `linux/arm64`。不再要求构建、分发、维护或验收 `linux/amd64` 容器，也不再索取原生 amd64/x86 目标环境；其缺失及 QEMU 沙箱失败不再构成当前发布阻塞。Intel/AMD 宿主不属于受支持的容器使用环境。宿主系统是否兼容仍须在受支持的 arm64 环境实测，不因本变更宣称所有 Mac/Windows/Linux 可用。

arm64 解析器继续要求 Linux 内核支持 Landlock/seccomp；固定版本/digest、原生依赖、HTTPS、权限、干净环境、性能、备份恢复及 RPO/RTO 要求保留。17 项适用发布门禁和任务硬前置不变，取消架构支持不等于测试通过或 S9 完成。

## 实施边界与历史

2026-10-13先同步需求、设计、计划、ADR、运行说明和台账；随后按用户“完成S9所有任务”续接实现。当前 `tools/s9/release.mjs` 和加载/发布Compose/冒烟入口按CHANGE-009仅支持arm64；实现及检查证据见[S9证据](../evidence/s9/README.md)。本决策不替代完整S9验收。

既有双架构包、amd64 构建/加载记录、模拟失败和历史交接原样保留，仅用于追溯，不作为当前支持承诺或待办。业务 API、数据模型、权限和数据迁移范围不变；不删除镜像、数据库、备份或持久卷。本变更不授权推送、部署或公开发布，也不据架构数量机械折算工时。
