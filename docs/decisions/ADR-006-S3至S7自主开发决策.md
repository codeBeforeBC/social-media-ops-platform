# ADR-006 S3至S7自主开发决策

日期：2026-10-08（Asia/Shanghai）。用户明确要求完成S3、S4、S5、S6、S7，每阶段完成先提交后进入下一阶段；缺失输入由Codex自行决策，无需询问。

1. 开发仍使用当前工作区main，不推送或发布产品；阶段提交包含代码、契约、必要测试、验收证据与台账。
2. 当前开发观察节点为本机Mac和已有Chrome档案zrcmcu2d。来源默认每天09:00/16:00、Asia/Shanghai；浏览器离线、登录失效或限流时独立暂停，不绕过平台控制。跨日窗口和真实登录恢复仍必须取得证据，不伪造时间记录。
3. 默认每源刷新最小间隔30分钟、每次不超过50条；小红书关键词默认旅行/潮玩/情绪价值，有界详情读取，公开文本保存供溯源，图片/视频不自动转为自有素材。
4. AI采用用户提供的DeepSeek/deepseek-flash。用户已允许任意数据、不设预算上限，仍保留超时、用量记录、结构校验、一次修复及任务取消。默认不把凭据打包或随clone传播。
5. 所有业务责任人为各本地实例实际使用者，保留组合权限和审计；素材任意来源及任意有效版本可选。
6. 为完成用户明确要求的完整S5，恢复该阶段必需的视频成片、音频及3D工程文件支持，补齐类型校验、代理与工程关联；此前S2的PNG/PDF验收历史保留。具体支持格式和真实验证证据在S5实施前收口，不宣称未验证兼容。
7. OCR优先选择可在默认Compose/Linux环境复现的本地方案，避免将Mac单机OCR探测视为产品能力；真实后台样本不存在时保留未验证，不将合成样本当后台。
8. 本地默认站内通知、用户自审、人工平台发布与开奖结果登记；实际平台发布与真实业务效果不由软件测试伪造。

后续自主决策在本文件追加；任务状态只维护在开发进度。

9. 小红书采用宿主机认证RPC连接现有浏览器，依赖在本地按版本锁安装；容器不携带浏览器登录态或用户凭据。没有Bridge配置时明确失败，连接器能独立暂停。
10. 微博接口可以返回超过50个上游条目，产品只读取配置限额（不超过50），保留上游条数；不因51条误报结构变化，不把榜单热度当阅读/互动。
11. 初始主题聚类按规范化标题分组并保留所有独立来源；不把相似标题的互动相加或删除原始证据。参考账号及IP入口仍需实际覆盖，不能以关键词读取替代其验收。

12. DeepSeek尚无已确认的本模型账单单价；真实token用量落库，费用明确记为未知。未来可配置带币种/版本的输入输出单价，计算仅为估算，不冒充供应商账单；有限额模式缺单价或额度时拒绝调用，历史未知消费不能静默当零。
13. AI业务输出采用严格结构和服务端引用白名单；候选最多6个，评分固定六项，视频连续主镜头必须匹配目标时长。输入、提示词、Schema、允许引用集合与验证器版本进入缓存标识；结果本身不执行采纳/审核/发布。

14. 采纳默认负责人为当前使用者，编辑只能采纳为本人任务；不同请求键重复采纳同一题仍返回同一内容/首版本/制作单Job，另做内容必须明确创建变体。采纳允许保留缺规范、素材及工时项，代表草稿而非审核通过。
15. 原创常青候选不得凭空填写到期时间，来源窗口结束不是到期；有时效来源按采集时间24小时计算最早时效边界，参考笔记允许常青但仍保留事实核验。已采纳内容保留，过期仅提示重验。选题证据显示生成时的不可变观察，后续来源标题变化不改写历史。
16. 新建视频制作单任务暂用15秒目标时长，缺配音允许明确不适用；S3-06补齐候选应用与可修改参数，不将排队Job或JSON分镜当成实际视频成品。

17. 制作单先生成冻结候选，人工采用才成为新草稿；确认目标、人群、关注理由始终保留，其他人工字段可按路径锁定。基础内容或修订变更拒绝自动采用，保留历史供人工比较；无素材的候选保留缺项，不能据此自动审核或发布。
18. 当前内容工作间提供制作单查看、候选比较和采用，完整编辑、审核、发布按S4/S5实施；图文最多30页、视频最多100个连续主镜头，生成画幅必须匹配指定画幅。

19. 用户最新目标收敛为仅完成S3（CHANGE-005）；本轮不推进S4–S7。前18条保留当时依据，其中S5扩展为历史后续规划，不作为本轮实施承诺。S3验收后仍按既有要求提交。
20. 固定评估采用明确合成来源/资产/指标与攻击文本，真实模型调用和实际来源验证分别记录；自动内容评审标为Codex评审，不冒充本地使用者人工验收。警告中引用“已拒绝”的攻击文本不等于越权，私人信息与公开文案仍逐例核对。
21. 事实引用只能逐字摘取对应冻结来源标题/摘要；原文存在不证明真实性。模型的解释、比较和推断分开保存，任务字段不能绑定来源ID当外部证明；生成和落库均校验。

22. 供应方截断或不可用响应明确失败；如已返回用量，仍记真实token及估算费用，未返回用量记未知。固定评估临时用16000输出token上限与90秒，不改产品默认值或重试次数。

23. 公开标题、正文、页文案及字幕只保存面向读者的草稿；内部版本/UUID/白名单/缺项/攻击诊断放内部说明。未提供证据的科学规律、确定效果和亲身经历不由模型补成事实，缺证据时给观察练习与问题。提示词v1.0.6/7完整固定评估保留失败对比。
24. 优质笔记支持最多两个公开参考账号ID，每源总条数仍不超过50。默认关键词补齐旅行/IP/潮玩/情绪价值；参考账号从当前实际搜索作者选取做技术验收，不暗示官方或优质背书。实际完成的关键词/账号与预算耗尽分别记录；每词及每账号最多一篇详情，外部媒体仅参考。
25. 原08设计允许用可控测试/模拟适配器验证登录失效等失败恢复，不要求主动退出真实账号；采用受控失效识别/暂停/通知，加真实已授权来源恢复读取的组合证据，不将其写成实际人工重新登录。来源短期观察采用2026-10-07/08/09真实读取和进程重连记录；原“三天六个09/16窗口”是开发者建议观察方案，不冒充这些窗口已执行或生产SLA。当前本机为运行节点，负责人是本地使用者，日常09/16按持久调度执行，离线不补写成功；跨平台和长期运行在S9验收。此条替代第2条中额外主动重新登录演练要求，保留08全部来源、字段、限流/超时/登录/结构变化和暂停恢复能力门禁。

26. 固定AI评估采用逐例自动技术语义评审，绑定输出哈希，五项均≥3且总分≥20；用户已授权开发中自行决策，该评审不能替代真实使用者的人工发布批准。制作限制逐例保留，不用均分抵消硬错。
27. 来源批次记录采集时间、分页游标及未知平台配额；未知值null，部分失败降级。详情错误保留诊断，认证/访问/限流即暂停，有限请求预算优先记录实际覆盖。
