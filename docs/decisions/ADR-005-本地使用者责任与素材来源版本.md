# ADR-005 本地使用者责任与素材来源版本

日期：2026-10-08（Asia/Shanghai）；状态：用户已确认；CHANGE-003。

## 负责人

每个本地实例由实际使用该实例的人承担账号登录恢复、素材和品牌规则核对、内容审核、发布登记、开奖、数据确认、AI质量评审、费用与运行维护等业务责任。当前为提出本次要求的用户；未来为clone项目并在本地启动的使用者。单人使用无需另找不同的负责人或备用人；多人实例按对象记录实际操作者，可选择其他成员负责。

业务对象仍保存本实例成员ID、操作者和审计记录。负责人默认取当前本地实例登录的使用者，不硬编码本项目用户或开发者身份。此约定不使只读角色获得写入权限，也不使不同实例、工作区或账号的数据互通。首次管理员设置沿用已有流程；未来模块按此约定实现默认值。

## 素材来源与版本

平台接受使用者选择的任意素材来源及任意素材版本，不限定官方来源、最新版本或某位特定人员确认；不再把额外来源证明、逐件外部授权材料或另找责任人作为本轮开发前置输入。来源、版本、使用记录仍用于追溯。当前用户对来源及版本不设限制的确认已记录；未来实例由其实际使用者管理自己的素材选择。

这里的“所有来源、版本”是来源与版本选择规则。文件格式继续遵循CHANGE-002：普通素材PNG，品牌规范PDF；视频和工程格式仍是下版范围，未据此宣称所有格式已支持。

现有资产接口未设置来源提供方或“仅最新版本”的白名单，因此本轮无需移除该类限制。不可变版本、历史引用、停用状态、真实解析可用性、账号隔离和内部审核继续按业务基线执行。现有界面的使用范围确认属于平台内状态操作，使用者本人可完成，不要求提交外部证明。未来制作流程须允许有效的历史资产版本，不强制切换为最新版本。

## 验证与实施边界

本轮同步设计、实施计划、输入模板和进度台账；未修改产品代码，不把负责人默认值或未来制作模块视为已实现。S3–S7实施时按对象落库、权限及版本引用测试验证。该决策不替代来源跨日观察、后台样本、OCR或视频真实文件验证。
